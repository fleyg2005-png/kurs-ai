Первая задача: ИИ сам делает и сохраняет

Агент прочитает ваши документы, перепишет README и сам сохранит результат в репозиторий. Вы откроете новый README и сверите таблицу с договором. Нашли ошибку — пишете замечание в ту же сессию, агент правит и снова сохраняет сам. На GitHub вы не нажмёте ни одной кнопки.

Что сейчас произойдёт

Вы: задача→ Агент читает документы→ Пишет README и сам сохраняет→ Отчёт: что сделано, какие файлы→ Вы: открыть и сверить→ Замечание → правка

Это цикл, по которому пойдёт каждая задача курса. В отчёте агента встретятся слова «коммит», «ветка», «pull request», «слил в main» — так он описывает, как сохранял работу. Делать с ними ничего не нужно. Для вас важно одно: «сохранил в main» значит, что новая версия уже лежит в репозитории и её видно на github.com.
