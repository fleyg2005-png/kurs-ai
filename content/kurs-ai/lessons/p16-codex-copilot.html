То же в ChatGPT (Codex) и Copilot

В прошлом уроке Claude Code переписал README репозитория shop и сам сохранил результат. Теперь ту же задачу — слово в слово — получат два других агента: Codex в ChatGPT и облачный агент Copilot на GitHub. Скажем честно, чем они отличаются, и как обойтись без кнопок на GitHub. Выберите вкладку под свою подписку.

Одна задача — любой агент

Агенты различаются кнопками, а не языком общения. Задача описывает результат — что прочитать, что написать, чего не трогать, что сказать в отчёте — и ничего не говорит о том, кто её выполняет. Поэтому текст из прошлого урока отдаём без единой правки:

Задача агенту — та же, что в прошлом уроке
Прочитай все файлы в репозитории. Ничего в карточках не меняй.
Сделай две вещи:
1. Перепиши README.md: что лежит в репозитории, список товаров таблицей (файл — название товара — цена — остаток — сколько отзывов в otzyvy/otzyvy.csv и средняя оценка; данные бери только из файлов, если чего-то нет — ставь «не указано»).
2. В конце README предложи 3 задачи, которые ты можешь выполнить по этим файлам автоматически, с оценкой: что получится на выходе.
В отчёте напиши, какие файлы ты прочитал и что в них непонятно.
Сохрани результат сам, как в правилах.

README уже переписан Claude — это не мешает, а помогает: второй агент сделает то же по-своему, и вы впервые сравните два результата — у кого таблица полнее, кто честнее ставит «не указано».

Чем Codex и Copilot отличаются от Claude Code

Они тоже работают с репозиторием: читают файлы, запускают программы на Python в изолированной копии и правила из AGENTS.md читают сами. Но результат оставляют pull request'ом — предложением изменений — и сами его не сливают в main. Правило 7 из AGENTS.md («сразу слей в main») они не выполнят, и это нормально.

Чтобы ничего не делать на GitHub руками:

  • в Codex нажмите его кнопку Create PR — это кнопка в самом Codex, а не на GitHub;
  • слить попросите Claude Code в его сессии: «Слей открытый pull request от Codex в main и удали его ветку»;
  • в Copilot задачу пишут в issue и назначают Copilot — это как написать задачу. Его pull request сливается так же, через Claude Code.

Основной инструмент курса — Claude Code. Он доводит задачу до конца сам. Codex и Copilot — запасной вариант, и их работу в main всё равно переносит Claude Code.

Два агента — два пути

Нужен ChatGPT Plus ($20/мес), Pro или Business — на Free и Go агента нет. Если вы подключали Codex в уроке 14, первые шаги уже пройдены — начните с шага «Start a new task».

Перейдите на chatgpt.com/codex. В приложении ChatGPT тот же раздел: Codex → Work in → Cloud; на телефоне — раздел Codex.

Нажмите Connect GitHub. GitHub предложит установить приложение Codex на ваш аккаунт и спросит, какие репозитории ему открыть: Select repositories → shop (или All repositories). Тот же принцип, что Claude GitHub App: приватный репозиторий агент видит только через своё приложение.

Select environment → Create environment → выберите shop. Окружение создаётся один раз — дальше все задачи по этому репозиторию идут в нём.

Get started

Нажмите Get started: Codex сам изучает проект и ставит зависимости. В репозитории с карточками программ пока нет, так что этап короткий. Проверьте, что выбран нужный репозиторий, и нажмите Publish. Подтверждение Environment published — окружение готово.

Нажмите Start a new task, вставьте задачу из начала урока и отправьте. Обратите внимание: вы ничего не меняли в тексте.

Задача выполняется в изолированной среде с копией репозитория, обычно от 1 до 30 минут. Codex показывает список изменённых файлов и что он делал. Изменённый файл должен быть один — README.md; если есть другие, агент нарушил условие «ничего в карточках не меняй» — повод для замечания.

Переписать README: состав репозитория и таблица товаров Done

Изменён 1 файл: README.md

Нужна правка — напишите её в той же задаче, там весь контекст: «В таблице у пледа отзывов „не указано“, хотя в otzyvy.csv есть три строки про плед — пересчитай».

Когда всё устраивает, нажмите кнопку Create PR в самом Codex. Это кнопка Codex, а не GitHub: он сам откроет pull request в вашем репозитории. Слить его в main он не может — это следующий шаг.

Откройте сессию Claude Code с репозиторием shop (окружение full, режим Auto) и решите, чей вариант оставить. Посмотреть версию Codex можно, не заходя на GitHub:

Вариант Codex лучше — попросите слить:

Запрос к Claude Code — слить

Лучше прежний — попросите: «Закрой открытый pull request от Codex без слияния и удали его ветку». В обоих случаях Claude Code напишет, что сделал.

Codex на GitHub. Codex также есть в GitHub Agent HQ: его можно назначить на issue так же, как Copilot на следующей вкладке.

Нужен Copilot Pro — $10/мес; бесплатно для студентов, преподавателей и мейнтейнеров популярных open source-проектов. Агент живёт на GitHub: задачу для него пишут в issue — как в задачнике.

Вскоре Copilot создаст pull request и напишет в нём план в виде чеклиста, отмечая пункты по мере работы. Работает он в GitHub Actions — облачных машинах GitHub. Можно уйти: когда закончит, он попросит проверить работу. Открывать pull request не нужно — проверку и слияние сделает Claude Code.

В сессии Claude Code с репозиторием shop попросите показать результат:

Запрос к Claude Code — показать
В репозитории есть открытый pull request от Copilot с новым README.md. Покажи его README прямо здесь, перечисли, какие файлы в нём изменены, и сравни таблицу с README в main. Ничего не меняй.

Нашли ошибку — попросите Claude Code исправить её прямо в работе Copilot: «В pull request от Copilot остаток рюкзака 150, а в tovary/ryukzak.md — 15. Исправь и перепроверь остальные числа по карточкам».

Запрос к Claude Code — слить
Слей открытый pull request от Copilot в main и удали его ветку.

Issue закроется, README на главной странице обновится. Версия Claude лучше — попросите: «Закрой открытый pull request от Copilot без слияния и удали его ветку»: в репозитории ничего не изменится.

Какой тариф ChatGPT нужен для Codex?

  • Go и выше
  • Plus, Pro или Business

На Free и Go Codex недоступен. Минимальный тариф с агентом — Plus за $20/мес.

Как запустить облачного агента Copilot?

  • Создать issue с задачей и назначить его на Copilot в блоке Assignees
  • Написать задачу в комментарии к последнему коммиту
  • Открыть README и нажать кнопку Copilot

Назначение issue на Copilot — и есть запуск. Это как написать задачу в задачник.

Что нужно изменить в тексте задачи, переходя от Claude Code к Codex или Copilot?

  • Убрать строку про сохранение — другие агенты её не поймут
  • Ничего: задача описывает результат и границы, а не исполнителя
  • Переписать на английский

Хорошая задача говорит, что прочитать, что сделать, чего не трогать и что написать в отчёте. Всё это одинаково для любого агента.

Codex закончил, вы нажали в нём Create PR. Как результат попадёт в main, если на GitHub вы ничего не нажимаете?

  • Codex сольёт его сам через несколько минут
  • Попросить Claude Code в его сессии: «Слей открытый pull request от Codex в main и удали его ветку»
  • Никак: результат Codex остаётся только в Codex

Codex и Copilot оставляют результат pull request'ом и сами его не сливают. Сливает Claude Code — по вашей просьбе в чате.

Почему основной инструмент курса — Claude Code?

  • Он единственный умеет читать карточки .md
  • Он доводит задачу до конца сам и сохраняет результат в main, а Codex и Copilot оставляют pull request, который кто-то должен слить
  • Он бесплатный

Все три агента работают с репозиторием, но сохранить в main сами может только Claude Code. Поэтому и чужие pull request сливает он.

Практика

Пройдите один из двух путей и сравните README второго агента с версией Claude: у кого таблица полнее, чьи три предложенные задачи вы бы поручили.

  • Я выбрал агента под свою подписку и дошёл по степперу до его pull request: Create PR в Codex или issue, назначенная на Copilot.
  • Агент получил задачу слово в слово — ту же, что Claude Code в прошлом уроке.
  • Через Claude Code я посмотрел README второго агента и сверил таблицу с карточками в tovary/ и выгрузкой otzyvy/otzyvy.csv; изменён только README.md.
  • Если агент ошибся в таблице, я передал замечание и получил правку.
  • Claude Code по моей просьбе слил pull request второго агента или закрыл его без слияния — и я могу назвать одну причину своего решения. На GitHub я ничего не нажимал, кроме issue для Copilot.

Теперь вы умеете работать с любым из трёх агентов. Следующий урок — как проверять результат и оставлять замечания так, чтобы агент понял с первого раза.
