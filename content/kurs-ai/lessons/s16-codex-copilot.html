То же в ChatGPT (Codex) и Copilot

Основной инструмент курса — Claude Code: он сам делает задачу и сам сохраняет её в main. Codex от OpenAI и облачный агент Copilot на GitHub тоже умеют работать с вашим репозиторием. Это запасные исполнители, у них есть одна оговорка. Разберём её и пройдём одну задачу в любом из них.

Честно о разнице

Codex и Copilot читают репозиторий, правят файлы и сохраняют работу. Но до main сами её не доводят: результат остаётся pull request'ом, то есть заявкой «перенеси черновик в main», и сами они её не сливают. Правило 6 из AGENTS.md они прочитают и честно напишут, что слить не могут. Пока заявка не принята, сайт не меняется.

Чтобы ничего не делать на GitHub руками:

  • в Codex нажмите его кнопку Create PR — это кнопка в самом Codex, а не на GitHub;
  • слить попросите Claude Code в его сессии: «Слей открытый pull request от Codex в main и удали его ветку»;
  • в Copilot задачу пишут в issue и назначают Copilot, это как написать задачу. Его pull request сливается так же, через Claude Code.

Два запасных пути

Нужен ChatGPT Plus ($20/мес), Pro или Business: на Free и Go агента нет. Откройте chatgpt.com/codex в соседней вкладке.

Перейдите на chatgpt.com/codex. В приложении ChatGPT тот же раздел: Codex → Work in → Cloud; на телефоне — раздел Codex.

Нажмите Connect GitHub. GitHub предложит установить приложение Codex на ваш аккаунт и спросит, какие репозитории ему открыть: Select repositories → hello-ai. Это тот же принцип, что у Claude GitHub App в уроке 14.

Select environment → Create environment → выберите репозиторий hello-ai. Окружение создаётся один раз, дальше все задачи по этому репозиторию идут в нём.

Get started

Нажмите Get started: Codex сам изучит проект. У сайта из простых файлов настраивать нечего, этап короткий. Проверьте, что выбран hello-ai, и нажмите Publish. Подтверждение Environment published значит, что окружение готово.

Нажмите Start a new task, вставьте задачу из начала урока и отправьте. Текст тот же, что для Claude, ничего не меняли.

Задача выполняется в отдельной среде с копией репозитория, обычно от 1 до 30 минут. Codex показывает изменённые файлы и логи команд. Файл должен быть один, index.html. Нужна правка — напишите её в той же задаче, Codex переделает.

Нужен Copilot Pro — $10/мес; бесплатно для студентов, преподавателей и мейнтейнеров популярных open source-проектов. Агент живёт на GitHub: задача — issue, результат — pull request.

В репозитории hello-ai откройте вкладку Issues → New issue. Issue — задачник репозитория. Написать issue — то же, что написать задачу в чате.

Справа в блоке Assignees выберите Copilot. Это и есть запуск: агент получил задачу.

Проверьте себя

Чем Codex и Copilot отличаются от Claude Code в этом пути?

  • Они не умеют менять файлы
  • Результат они оставляют pull request'ом и сами его не сливают
  • Они работают только с приватными репозиториями

Работу они делают, но до main не доводят. Слить их pull request можно попросить Claude Code.

Где находится кнопка Create PR, которую вы нажимаете в пути Codex?

  • На GitHub, во вкладке Pull requests
  • В самом Codex, на странице задачи
  • В настройках репозитория

Это кнопка Codex: она отправляет его работу в репозиторий. На GitHub вы ничего не нажимаете.

Как поставить задачу облачному агенту Copilot?

  • Создать issue с задачей и назначить Copilot в блоке Assignees
  • Написать задачу в CLAUDE.md
  • Отправить задачу в чат Claude Code

Issue — карточка задачи. Назначение на Copilot запускает агента.

Codex закончил задачу, вы нажали Create PR. Изменился ли сайт?

  • Да, сразу
  • Да, через минуту-две
  • Нет: сайт изменится, когда Claude Code сольёт pull request в main

Сайт показывает только main. Pull request — заявка, которая ждёт слияния.

Практика

Пройдите один из двух путей, если у вас есть подписка. Нет ни ChatGPT Plus, ни Copilot Pro — отдайте задачу Claude Code, как в уроке 15, и прочитайте урок для понимания.

  • Задача отправлена Codex или Copilot слово в слово, с моими пунктами вместо примера.
  • Агент изменил только index.html.
  • Pull request открыт кнопкой в Codex или самим Copilot; на GitHub я ничего не нажимал(а).
  • Claude Code описал изменения простыми словами и слил pull request в main.
  • Раздел «Чем могу помочь» появился на сайте.

У вас есть запасные исполнители. Задача одна для всех, сливает всегда Claude Code. Следующий урок — как проверять результат любого из них, глядя на сайт, а не в код.
