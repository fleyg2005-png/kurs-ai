Подключить GitHub к Claude и ChatGPT

Репозиторий с постами есть. Теперь даём к нему доступ ИИ: три способа для Claude и один для ChatGPT, каждый — по шагам «нажал → увидел». В конце главного способа агент по первому запросу сам создаст в репозитории правила, чеклист, шаблон отчёта и письмо рассылки и сам их сохранит, а вы откроете репозиторий и увидите новые файлы.

Два режима: дать почитать и дать поработать

Подключений несколько, и путаница начинается здесь. Разница простая.

В этом пути главный режим — второй, и главный инструмент — Claude Code. Первый режим пригодится для быстрых вопросов, когда программа не нужна.

Тарифы на октябрь 2026. Claude Code в браузере работает на Pro, Max и Team; на Free его нет. Codex в ChatGPT — на Plus, Pro и Business. Кнопка + → Add from GitHub в чате Claude доступна после подключения коннектора GitHub в настройках.

Способ 2. Кнопка «+» в чате: дать почитать

Для вопросов по постам и выгрузкам без программ. Один раз подключаете коннектор, потом добавляете файлы в любой чат.

В claude.ai откройте настройки: Customize → Connectors, найдите GitHub и нажмите подключить. GitHub попросит войти и разрешить доступ — как в способе 1. Для приватного репозитория нужно то же приложение Claude GitHub App; если вы ставили его в шаге 3 способа 1, ничего делать не нужно.

Начните новый чат. В левом нижнем углу поля ввода нажмите + и выберите Add from GitHub.

Запрос к ИИ
Сверь приложенный пост с чеклистом. Таблицей: пункт чеклиста — выполнено / не выполнено / неясно — цитата из поста. Только из текста, ничего не додумывай.

Claude ответит в чате. В репозитории ничего не изменится — это режим «почитать».

Три ограничения режима «почитать». Claude видит только выбранные файлы и только их содержимое — не историю изменений. Файлы не обновляются сами: после изменений в репозитории выбирайте их заново. Приватный репозиторий открывается, только если на него установлено приложение Claude; если доступа нет, Claude покажет ссылку на его установку.

Способ 3. Файлы репозитория в проекте Claude

Если вы заводили проект в уроке 10, посты из репозитория можно положить прямо в его знания: в разделе знаний проекта нажмите + → GitHub → найдите репозиторий или вставьте адрес → выберите файлы и папки. Они будут видны во всех чатах проекта. Когда посты в репозитории изменились, нажмите Sync — подтянется свежая версия; состав файлов меняется через Configure files. Это удобнее, чем добавлять файлы в каждый чат, но правило то же: выбирайте только нужное.

Способ 4. ChatGPT: Codex

Тот же режим «поработать», только у OpenAI. Нужен Plus, Pro или Business. Codex — запасной вариант: работать с репозиторием он умеет, но свой результат оставляет pull request'ом и сам его не сливает. Поэтому первый запрос отдайте Claude Code, а в Codex сейчас достаточно проверить, что он видит файлы. Как работать с ним дальше — в уроке 16.
