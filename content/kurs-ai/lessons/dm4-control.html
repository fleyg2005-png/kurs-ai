Контрольная 4: GitHub подключён к ИИ

Без подсказок и степперов: создайте второй приватный репозиторий с документами, откройте его ИИ-агенту, попросите агента записать в него правила и проверьте, что правила работают. Руками — только репозиторий и загрузка документов, остальное — запросы. Всё это вы делали в уроках модуля.

Задание

  1. Создайте новый приватный репозиторий с README. Имя — под свою профессию, латиницей: templates-hr, accounting-docs, tenders.
  2. Загрузите в него 2–3 обезличенных документа — регламент, шаблон приказа, типовой договор — через Add file → Upload files → Commit changes.
  3. Откройте репозиторий Claude Code: установите Claude GitHub App на этот репозиторий (github.com/apps/claude/installations/new → аккаунт → репозиторий) и выберите его в селекторе на claude.ai/code. Окружение — full, режим — Auto.
  4. Первым запросом попросите агента создать в корне AGENTS.md и CLAUDE.md. Текст правил возьмите из первого запроса урока 14: правила 1–5 и блок «Как сохранять работу» с правилами 6–9. Пункт 4 перепишите под свой репозиторий: «Документы в этом репозитории не меняй и не удаляй без прямой просьбы». В запросе обязательна строка «Ветки и pull request создавай сам и сразу сливай в main — я на GitHub ничего не нажимаю.» Убедитесь на github.com, что оба файла появились.
  5. Дайте тестовую задачу и дождитесь ответа в сессии:
    Задача агенту
    Перечисли файлы репозитория и кратко опиши каждый: что это за документ и о чём он. Ничего не меняй: не создавай, не правь и не сохраняй файлы. Ответь списком здесь.
  6. Проверьте правила агента. На компьютере создайте текстовый файл raspiska.txt с выдуманными данными ниже и загрузите его в корень репозитория через Upload files. Начните новую сессию: агент берёт копию репозитория в начале сессии, и в старой нового файла может не быть. Дайте ту же тестовую задачу. Агент должен остановиться и назвать файл, строку и что нашёл. Затем попросите его же: «Удали тестовый файл raspiska.txt из репозитория. Сохрани результат сам, как в правилах».
    Файл raspiska.txt — выдуманные данные для теста
    # Расписка

Я, Иванов Пётр Сергеевич, паспорт 45 00 123456, проживающий по адресу: г. Москва, ул. Примерная, д. 1, кв. 1, получил от Петрова Ивана Олеговича 50 000 рублей.
Телефон: +7 900 000-00-00
  7. Дополнительно: в обычном чате Claude нажмите + слева внизу поля ввода → Add from GitHub → этот репозиторий → один файл → задайте по нему вопрос: «Какие сроки указаны в этом документе?».

Критерии приёмки

Отмечайте только то, что проверили своими глазами. Чеклист и квиз ниже засчитывают контрольную автоматически.

  • Репозиторий существует, рядом с именем значок Private, в нём README и 2–3 документа без ФИО, ИНН, адресов и телефонов.
  • Репозиторий виден в селекторе на claude.ai/code; сессия идёт в окружении full и режиме Auto.
  • AGENTS.md и CLAUDE.md создал и сохранил агент по моему запросу: в них правила 1–5 и блок «Как сохранять работу», я вижу оба файла на github.com.
  • Агент ответил на тестовую задачу списком всех файлов с описанием каждого, и список совпадает с тем, что я вижу на github.com.
  • После тестовой задачи в репозитории ничего не изменилось: список файлов на github.com прежний.
  • Тест правил: на файле с выдуманными данными агент в новой сессии остановился и назвал файл и строку; тестовый файл агент удалил по моей просьбе.
  • В обычном чате Claude я добавил(а) файл через + → Add from GitHub и получил(а) ответ по его содержимому.
  • Я могу объяснить одной фразой, чем «дать почитать» (+ в чате, проект) отличается от «дать поработать» (Claude Code).
  • Я знаю, какая подписка нужна агенту и что GitHub при этом остаётся бесплатным.

Проверка понимания

Зачем агенту репозиторий, если документ можно вставить в чат?

  • В чат нельзя вставить документ длиннее одной страницы
  • Агент работает с файлами: читает документы и правила из репозитория в каждой задаче, запускает программу и сохраняет результат туда же; контекст не слетает между чатами
  • Репозиторий нужен только для оплаты подписки

В чате агенту негде хранить документы, правила и результаты. Репозиторий — его постоянная рабочая папка.

Вы создали приватный репозиторий, но в селекторе на claude.ai/code его нет. Самая вероятная причина?

  • Репозиторий должен быть публичным
  • Нужен тариф Max
  • На этот репозиторий не установлено Claude GitHub App

Публичные репозитории доступны сразу после Sign in with GitHub, приватные — только после установки Claude GitHub App.

Кто создаёт в новом репозитории AGENTS.md и CLAUDE.md?

  • GitHub, вместе с README
  • Вы, через Add file → Create new file
  • Агент, по вашему первому запросу с готовым текстом правил, — и сам сохраняет их

Руками вы создаёте репозиторий и загружаете документы. Служебные файлы — работа агента.

Чем «+ → Add from GitHub» в чате отличается от задачи в Claude Code?

  • Через + Claude читает выбранные файлы и отвечает в чате, ничего не меняя; Claude Code работает в копии репозитория, меняет файлы и сам сохраняет результат
  • Через + Claude видит ещё и историю всех изменений
  • Разницы нет — это один и тот же инструмент в двух местах

«Дать почитать» — + в чате и проект — ничего в репозитории не меняет. «Дать поработать» — Claude Code: своя машина, файлы, сохранение результата.

Что видит Claude, когда вы добавили файлы через +?

  • Весь репозиторий целиком, включая историю изменений
  • Имена и содержимое выбранных файлов; после изменений в репозитории их нужно выбрать заново
  • Только имена файлов, без содержимого

Claude видит ровно то, что вы отметили в файловом браузере. Автоматически не обновляется.

Что из этого платное?

  • Приватные репозитории на GitHub
  • Установка Claude GitHub App
  • Сам агент: Claude Code нужен тариф Pro, Max или Team; Codex — Plus, Pro или Business

GitHub с приватными репозиториями бесплатен, приложение тоже. На бесплатных тарифах Claude и ChatGPT агентов нет.

Почему для проверки правил агента берут выдуманные данные, а не настоящий документ?

  • Настоящие данные агент не распознаёт
  • Файл попадает на GitHub раньше, чем его увидит агент, и после удаления остаётся в истории репозитория
  • Правила агента работают только на тестовых файлах

Правила — второй контроль: агент ловит то, что пропустил человек, но загрузку не отменяет. Поэтому для теста — только выдумка, а настоящие персональные данные в репозиторий не кладут вовсе.

Если не получается

Репозитория нет в селекторе

Репозиторий приватный, а Claude GitHub App на него не установлено. Откройте github.com/apps/claude/installations/new, выберите аккаунт и репозиторий, вернитесь и обновите список.

Агент пишет, что документов нет

Агент видит только то, что лежит в репозитории на GitHub, а не на вашем компьютере. Если на github.com файлов нет в списке — загрузка не завершена кнопкой Commit changes. Проверьте и ветку в селекторе: main.

Файлы правил не появились

Проверьте окружение full и режим Auto, а в запросе — строку «Ветки и pull request создавай сам и сразу сливай в main — я на GitHub ничего не нажимаю». Агент пишет, что сохранить не получилось, — попросите объяснить простыми словами, что мешает.

Агент не остановился на тестовом файле

Проверьте, что AGENTS.md и CLAUDE.md лежат в корне репозитория, а не в папке, и что сессия новая. Не помогло — начните задачу словами «Сначала прочитай CLAUDE.md и следуй ему». И запомните: правила срабатывают не всегда, поэтому главная защита — не класть персональные данные в репозиторий.

Add from GitHub не показывает репозиторий

GitHub должен быть подключён в коннекторах: Customize → Connectors → GitHub. Для приватного репозитория без приложения Claude появится ссылка на его установку — установите и повторите. Адрес репозитория можно вставить в строку поиска.

Если причина непонятна — не угадывайте, спросите ИИ. Готовый запрос:

Запрос к ИИ
Я подключаю приватный репозиторий GitHub к Claude Code (claude.ai/code).
Репозиторий: https://github.com/USERNAME/templates-hr, приватный: README.md и три файла .docx.
Вошёл через Sign in with GitHub, нажал Authorize. Окружение full, режим Auto.
Проблема: [репозитория нет в селекторе / репозиторий есть, но агент пишет, что файлов нет / агент не сохранил файлы правил].
Claude GitHub App я [установил на все репозитории / только на другой репозиторий / не устанавливал].
Назови 3 самые вероятные причины по убыванию вероятности и для каждой — проверку за минуту, без установки программ.

Сдали? Значит, у ИИ есть ваша рабочая папка, доступ к ней и правила работы. Дальше — модуль 5: первая настоящая задача, в которой агент сам делает работу и сам сохраняет результат.
