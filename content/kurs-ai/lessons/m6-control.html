Контрольная 6: задача агенту и ревью

Без подсказок и степперов: сделайте сами полный цикл — ТЗ, агент, ревью с замечаниями, слитый PR, обновлённый сайт. Всё это вы делали в уроках 19–22.

Задание

  1. Выберите агента: Claude Code в браузере, Codex, Copilot cloud agent или бесплатный Copilot в режиме Agent в Codespaces.
  2. Напишите по шаблону урока 19 ТЗ на новую функцию для hello-ai. Варианты: раздел «Контакты» с формой (имя, почта, сообщение), которая по кнопке показывает «Спасибо, сообщение получено» и ничего не отправляет; переключатель тёмной темы; калькулятор для своей профессии (не пени — он уже есть).
  3. Запустите агента. В Claude Code — окружение full и режим Auto. Последняя строка ТЗ — «Сделай ветку и pull request сам, как в правилах»: pull request агент откроет сам (в Codex — его кнопкой Create PR, в Copilot — из issue). В Codespaces ветку и PR создайте сами.
  4. Проведите ревью по чеклисту урока 22. Оставьте минимум два замечания — в diff или комментариях PR — и добейтесь исправления.
  5. Слейте PR и убедитесь, что сайт обновился и функция работает по примеру из ТЗ.
  6. Запишите в README.md одну строку о новой функции — руками (карандаш) или задачей агенту.

Критерии приёмки

Отмечайте только то, что проверили своими глазами. Чеклист и квиз ниже засчитывают контрольную автоматически.

  • Моё ТЗ содержит все шесть частей: цель, где, поведение с примером, критерии готовности, чего не трогать, ограничения.
  • Ветку и PR создал агент (в Codespaces — я сам), это не коммит в main; из описания понятно, что изменилось и зачем.
  • В PR минимум два моих замечания, и после них агент прислал изменения, где они учтены.
  • Во вкладке Files changed тронуты только файлы, разрешённые в ТЗ.
  • В коде нет ключей, паролей, личных данных и скриптов с чужих сайтов — проверено по чеклисту урока 22.
  • PR слит (Merge pull request → Confirm merge); сайт в инкогнито показывает новую функцию, пример из ТЗ даёт ожидаемый результат.
  • В README.md появилась строка о новой функции, коммит виден в истории.

Проверка понимания

Чем ИИ-агент отличается от чата с ИИ?

  • Агент отвечает быстрее и длиннее
  • Агент сам читает и меняет файлы в репозитории, запускает проверки и исправляет ошибки
  • Агент работает без репозитория, с любым текстом

Чат выдаёт текст, агент действует в проекте и присылает результат веткой с pull request.

Какой режим Claude Code выбрать, чтобы агент сам довёл задачу до pull request?

  • Auto
  • Plan
  • Accept edits

В Auto Claude сам решает, что можно делать без вопросов. Plan сначала показывает план и ждёт одобрения, Accept edits сам принимает только правки файлов, остальное спрашивает.

Что нужно, чтобы назначить issue на Copilot и получить pull request?

  • Любой аккаунт GitHub, бесплатно
  • Подписка ChatGPT Plus
  • Copilot Pro ($10/мес) или выше; бесплатно — студентам, преподавателям и мейнтейнерам

Облачный агент входит только в Copilot Pro и выше; на Copilot Free есть лишь режим Agent в редакторе.

Как работать с агентом без платной подписки?

  • Никак: все агенты платные
  • Открыть репозиторий в Codespaces и включить в Copilot Chat режим Agent; ветку, коммит и PR сделать самому
  • Использовать Claude Code на тарифе Free

Codespaces даёт 120 core-часов в месяц, Copilot Free — режим Agent с лимитами. Claude Code и Codex без подписки недоступны.

Что проверить в PR от агента в первую очередь, не читая код?

  • Список тронутых файлов и результат на сайте по примеру из ТЗ
  • Количество строк кода
  • Скорость работы агента

Лишние файлы и несовпадение с примером видны без знания программирования. Объём кода и скорость ни о чём не говорят.

Какая из ситуаций — красный флаг, при котором PR сливать нельзя?

  • Агент добавил к результату знак ₽, которого не было в ТЗ
  • Агент вынес стили в отдельный файл style.css
  • Агент вставил в index.html ключ API для загрузки курса валют с внешнего сервиса

Ключ на публичном сайте увидит любой, а внешнего сервиса в ТЗ не было. Первые два — повод для замечания, но не опасность.

Если не получается

Агент не видит репозиторий или не запускается

Claude Code: нужен Pro, Max или Team; для приватного репозитория — Claude GitHub App; не может скачать нужное — проверьте, что выбрано окружение full. Codex: не подключён GitHub или окружение не опубликовано. Copilot cloud agent: нет Copilot Pro. Упёрлись — берите бесплатный путь из урока 21: контрольная засчитывается с любым агентом.

Агент не открыл pull request

Напишите в ту же сессию: «Сделай ветку и pull request сам, как в правилах, и пришли ссылку». Нет в репозитории CLAUDE.md и AGENTS.md — попросите агента создать их с текстом правил из урока 20, шаг 7.

Агент сделал не то или тронул лишнее

Не сливайте. Напишите замечание с конкретикой: файл, строка, что ожидали. Если результат далёк от ТЗ целиком — закройте PR, уточните ТЗ (обычно не хватает примера и «чего не трогать») и запустите заново.

PR слит, а сайт не изменился

Подождите 1–10 минут и обновите страницу с очисткой кеша. Проверьте, что PR слит в main и что в Settings → Pages выбрана ветка main. Нет новой функции в index.html в репозитории — PR слит не туда.

Если причина непонятна — спросите ИИ. Готовый запрос:

Запрос к ИИ
Я поставил задачу ИИ-агенту в репозитории https://github.com/USERNAME/hello-ai (публичный, сайт на GitHub Pages).
Агент: [Claude Code / Codex / Copilot cloud agent / Copilot в Codespaces].
Моё ТЗ: [текст ТЗ целиком].
Что сделал агент: [какие файлы изменены, что написал в ответе или описании PR].
Что не так: [что вижу и что ожидал; если есть ошибка — её точный текст].
Назови 3 самые вероятные причины в порядке вероятности, для каждой — как проверить за минуту, и предложи текст замечания агенту.
