Без подсказок и степперов: доведите репозиторий marketing до полного состава, загрузите в него новый пост через Upload files, проверьте подключение агента задачей, после которой в репозитории ничего не меняется, и убедитесь, что правила агента работают. Всё это вы делали в уроках модуля.

Критерии приёмки

Отмечайте только то, что проверили своими глазами. Чеклист и квиз ниже засчитывают контрольную автоматически.

  • Репозиторий marketing существует, рядом с именем значок Private, в корне README.md, checklist.md, AGENTS.md и CLAUDE.md, в posts/ не меньше четырёх постов — и ни в одном файле нет персональных данных клиентов и подписчиков.
  • В AGENTS.md и CLAUDE.md есть раздел «Как сохранять работу»: ветки и pull request агент создаёт и сливает сам.
  • Новый пост загружен через Upload files: он виден в posts/ на github.com, а в истории появилась моя запись с понятной подписью.
  • Репозиторий виден в селекторе на claude.ai/code; окружение full и режим Auto выбраны.
  • Агент ответил списком всех файлов с описанием каждого, включая новый пост, и список совпадает с тем, что я вижу на github.com.
  • После тестовой задачи в репозитории ничего не изменилось: агент написал, что ничего не менял, а на github.com подписи и время у файлов прежние.
  • Тест правил: на файле с выдуманными данными агент в новой сессии остановился и назвал файл и строку; по моей просьбе он удалил тестовый файл и сохранил сам — на github.com его нет.
  • В обычном чате Claude через + → Add from GitHub (или в знаниях проекта через + → GitHub) я добавил пост и получил ответ по его содержимому.

Проверка понимания

Вы загрузили новый пост через Upload files и нажали Commit changes. Что произошло?

  • Пост отправлен агенту на проверку
  • Файл сохранён в репозиторий, и в истории появилась запись с моей подписью
  • Пост опубликован на площадке

Upload files — «положить файл в папку», Commit changes — «сохранить с подписью». Публиковать посты из репозитория никто не будет: публикация остаётся за вами.

Вы создали приватный репозиторий, но в селекторе на claude.ai/code его нет. Самая вероятная причина?

  • Репозиторий должен быть публичным
  • Нужен тариф Max
  • На этот репозиторий не установлено Claude GitHub App

Публичные репозитории доступны сразу после Sign in with GitHub, приватные — только после установки Claude GitHub App.

Чем «+ → Add from GitHub» в чате отличается от задачи в Claude Code?

  • Через + Claude читает выбранные файлы и отвечает в чате, ничего не меняя; Claude Code работает в копии репозитория, меняет файлы и сам сохраняет результат в репозиторий
  • Через + Claude видит ещё и историю изменений и issues
  • Разницы нет — это один и тот же инструмент в двух местах

«Дать почитать» — + в чате и проект — ничего в репозитории не меняет. «Дать поработать» — Claude Code: своя машина, и сохраняет он сам.

Что видит Claude, когда вы добавили посты через +?

  • Весь репозиторий целиком, включая историю коммитов
  • Имена и содержимое выбранных файлов; после изменений в репозитории их нужно выбрать заново
  • Только имена файлов, без содержимого

Claude видит ровно то, что вы отметили в файловом браузере: не историю и не issues. Автоматически не обновляется; в знаниях проекта свежую версию подтягивает кнопка Sync.

Что из этого платное?

  • Приватные репозитории на GitHub
  • Установка Claude GitHub App
  • Сам агент: для Claude Code нужен тариф Pro, Max или Team; для Codex — Plus, Pro или Business

GitHub с приватными репозиториями бесплатен, приложение тоже. На бесплатных тарифах Claude и ChatGPT агентов нет.

Почему для проверки правил агента берут выдуманные данные, а не настоящий документ?

  • Настоящие данные агент не распознаёт
  • Файл попадает на GitHub раньше, чем его увидит агент, и после удаления остаётся в истории
  • Правила агента работают только на тестовых файлах

Правила — второй контроль: агент ловит то, что пропустил человек, но загрузку не отменяет. Поэтому для теста — только выдумка, а настоящие персональные данные в репозиторий не кладут вовсе.

Если не получается

Репозитория нет в селекторе

Claude Code: репозиторий приватный, а Claude GitHub App на него не установлено — откройте github.com/apps/claude/installations/new, выберите аккаунт и репозиторий, вернитесь и обновите список. Codex: репозиторий должен быть в списке репозиториев, открытых приложению Codex; затем создайте окружение.

Агент пишет, что постов нет

Агент видит только то, что лежит в репозитории на GitHub, — не ваши заметки и не файлы на компьютере. Если на github.com постов нет в списке — загрузка не завершена кнопкой Commit changes. Проверьте и ветку в селекторе: main.

Агент спрашивает, можно ли сохранить

Проверьте режим под полем ввода: нужен Auto. И что в CLAUDE.md есть раздел «Как сохранять работу» — без него агент может ждать от вас действий на GitHub. Нет раздела — отправьте первый запрос из урока 14 ещё раз.

Add from GitHub не показывает репозиторий

GitHub должен быть подключён в коннекторах: Customize → Connectors → GitHub. Для приватного репозитория без приложения Claude появится ссылка на его установку — установите и повторите. Адрес репозитория можно вставить в строку поиска.

Агент не остановился на тестовом файле

Проверьте, что AGENTS.md и CLAUDE.md лежат в корне репозитория, а не в папке, и что сессия новая. Не помогло — начните задачу словами «Сначала прочитай CLAUDE.md и следуй ему». И запомните: правила срабатывают не всегда, поэтому главная защита — не класть персональные данные в репозиторий.

Если причина непонятна — не угадывайте, спросите ИИ. Готовый запрос:

Запрос к ИИ
Я подключаю приватный репозиторий GitHub к Claude Code (claude.ai/code).
Репозиторий: https://github.com/USERNAME/marketing, приватный: README.md, checklist.md, CLAUDE.md и папки posts, campaigns, templates.
Вошёл через Sign in with GitHub, нажал Authorize. Окружение full, режим Auto.
Проблема: [репозитория нет в селекторе / репозиторий есть, но агент пишет, что файлов нет].
Claude GitHub App я [установил на все репозитории / только на другой репозиторий / не устанавливал].
Назови 3 самые вероятные причины по убыванию вероятности и для каждой — проверку за минуту, без установки программ.

Сдали? Значит, у ИИ есть ваша рабочая папка и доступ к ней. Дальше — модуль 5: первая настоящая задача, которую агент сам делает и сам сохраняет.
