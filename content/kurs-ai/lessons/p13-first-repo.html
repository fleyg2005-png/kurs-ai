Репозиторий с карточками товаров для ИИ

Восемь минут — и у вас есть приватный репозиторий shop с вашими карточками товаров и выгрузкой отзывов. Руками вы делаете только две вещи: создаёте репозиторий и загружаете файлы. Правила для агента, чеклист и шаблон ответа в следующем уроке создаст сам ИИ. Войдите на github.com в соседней вкладке и идите по шагам.

Что получится

Это сквозной проект курса: все задачи агентам в следующих модулях — про этот репозиторий. К концу урока в нём лежат ваши файлы, а в следующем уроке агент добавит к ним служебные:

README.md tovary/ — 3–4 карточки товаров (.md): ryukzak.md, lampa.md, pled.md… в каждой — название, описание, характеристики, комплектация, цена, остаток otzyvy/otzyvy.csv — выгрузка отзывов: артикул; товар; оценка; текст отзыва — в уроке 14 по первому запросу агент создаст сам: AGENTS.md, CLAUDE.md — правила для агента: персональные данные, что не трогать, как сохранять работу checklist.md — чеклист карточки товара, 10 пунктов templates/otvet-na-otzyv.md — шаблон ответа на отзыв с полями {имя}, {товар}, {проблема}, {решение} tovary/termokruzhka.md — контрольная карточка термокружки — в модуле 6: reports/, summary.md — отчёты по карточкам и сводная таблица

Сейчас нужны только карточки и отзывы — то, что знаете вы, а не агент.

Запрос к ИИ — три учебные карточки
Напиши три учебные карточки товаров для маркетплейса, каждую отдельным файлом, перед каждой — имя файла: ryukzak.md, lampa.md, pled.md. Карточки тренировочные, бренд выдуманный — Norvik; реальных артикулов и названий магазинов быть не должно.
Первой строкой — название по формуле «тип + бренд + модель + главный признак» с решёткой. Дальше разделы с подзаголовками: Описание (от 500 знаков: для кого товар, чем отличается — без преувеличений); Характеристики (габариты, материал, цвет); Комплектация; Ключевые слова (8–10 поисковых запросов); Цена (цена и цена до скидки); Остаток; Вопрос покупателя (с ответом); Условия возврата.
Первая — # Рюкзак Norvik City 20 л с отделением для ноутбука: цена 2 490 ₽, цена до скидки 3 290 ₽, остаток 15 шт. Вторая — # Лампа настольная Norvik Lume с регулировкой яркости: цена 1 590 ₽, цена до скидки 1 990 ₽, ключевые слова есть, а разделы «Остаток» и «Условия возврата» не включай — пусть их в карточке не будет. Третья — # Плед Norvik Soft 130 × 170 см из микрофибры: цена 1 190 ₽, цена до скидки 1 690 ₽, остаток 58 шт., все разделы на месте.
Выдай только тексты карточек, без пояснений.
Запрос к ИИ — учебная выгрузка отзывов
Сделай учебную выгрузку отзывов: файл CSV, колонки через точку с запятой: артикул;товар;оценка;текст отзыва. 12 строк по четырём товарам (артикулы TK-450, RK-20, LM-01, PL-130), оценки строго такие: термокружка — 3 отзыва с оценками 5, 4, 3; рюкзак — 1 отзыв с оценкой 5; лампа — 5 отзывов с оценками 5, 4, 4, 3, 3; плед — 3 отзыва с оценкой 5. В отзывах с оценкой 3 — понятная проблема: у термокружки подтекает крышка, у лампы — мигает свет и пришёл не тот цвет. В конце текста каждого отзыва — условная подпись покупателя: имя и первая буква фамилии, например Анна К. Первой строкой — заголовки колонок.

Карточка лампы специально без остатка и условий возврата: инструмент в модуле 6 должен уметь честно написать «не выполнено». Отзывы на термокружку в выгрузке есть уже сейчас, хотя саму карточку создаст агент, — так и задумано.

Создайте на компьютере папку tovary: вставьте тексты карточек в Блокнот или другой текстовый редактор и сохраните каждую отдельным файлом с расширением .md — ryukzak.md, lampa.md, pled.md. Рядом — папку otzyvy с файлом otzyvy.csv: своя выгрузка с условными именами покупателей, приведённая к четырём колонкам, или учебная от ИИ.

На главной странице репозитория нажмите Add file → Upload files и перетащите обе папки — tovary и otzyvy — в окно загрузки. Папки на GitHub появятся вместе с файлами.

Commit changes — это просто «сохранить»

Нажатие Commit changes создало коммит — сохранение с подписью, которое видно в истории. Ничего больше за этим словом нет: «сохранить файлы и подписать, что сделано».

Дальше сохраняет агент. Получил задачу — сделал работу — сохранил сам и написал, какие файлы изменил. Ваши новые карточки и свежие выгрузки вы и дальше загружаете той же кнопкой Upload files.

Почему Private и что это значит для агента

Приватный репозиторий видят только вы и те, кого вы добавили. Для рабочих файлов магазина — цен, остатков, текстов карточек — единственный разумный выбор. Следствие: ИИ-агенту он тоже не виден, пока вы не дадите доступ. Публичные репозитории Claude Code видит сразу после входа через GitHub, а для приватного нужно установить приложение Claude GitHub App и выбрать в нём ваш аккаунт и репозиторий shop; у Codex для этого своё приложение. Как это сделать — в следующем уроке.

Private не отменяет правила про персональные данные. Файлы будет читать агент на своей облачной машине. Карточки, цены и остатки можно загружать как есть, а персональные данные покупателей — нет: настоящие имена, телефоны, адреса. Перед загрузкой пройдитесь поиском по выгрузке отзывов. Если данные всё же попали в репозиторий, удалить файл мало: старая версия остаётся в истории. Проще удалить репозиторий целиком — Settings → внизу страницы Delete this repository — и создать заново.

Проверьте себя

Почему репозиторий shop сделан приватным?

  • Приватные репозитории агент обрабатывает быстрее
  • Публичные репозитории на бесплатном тарифе недоступны
  • В нём цены, остатки и тексты карточек: приватный репозиторий видят только вы и те, кого вы добавили, а агенту доступ даётся отдельно через приложение

И публичные, и приватные репозитории бесплатны. Разница — кто видит файлы: публичный — все, приватный — только вы и те, кому открыт доступ.

Что делает кнопка Commit changes при загрузке карточек и отзывов?

  • Отправляет файлы ИИ-агенту на проверку
  • Сохраняет файлы в репозиторий и записывает это в историю с подписью
  • Публикует карточки на маркетплейсе

Здесь коммит — просто «сохранить с подписью». С маркетплейсом репозиторий не связан: это ваша подготовительная кухня.

Как в репозитории появились папки tovary и otzyvy?

  • Их перетащили целиком в окно Upload files — папки появились вместе с файлами
  • Через кнопку New folder в меню Add file
  • Их создал GitHub при создании репозитория

Отдельной кнопки для папок нет: папка появляется вместе с первым файлом в ней.

Кто и когда создаст в репозитории AGENTS.md, CLAUDE.md, checklist.md и шаблон ответа на отзыв?

  • Вы, через Add file → Create new file, прямо сейчас
  • Агент, по первому запросу в следующем уроке: тексты этих файлов уже вписаны в запрос
  • GitHub, автоматически при создании приватного репозитория

Руками вы только создаёте репозиторий и загружаете свои файлы. Служебные файлы агент создаст и сохранит сам.

Что нужно убрать из выгрузки отзывов перед загрузкой?

  • Цены и остатки товаров
  • Настоящие имена, телефоны и адреса покупателей — заменить имена на условные вроде «Анна К.»
  • Названия товаров и артикулы

Обезличивать карточки и цены не нужно — только персональные данные людей. Агент будет читать эти файлы на своей машине.

  • В корне есть README.md, в папке tovary/ — 3–4 карточки, каждая открывается в браузере как текст.

  • Ни в одном файле нет персональных данных покупателей — ФИО, телефонов, адресов; имена в отзывах условные. Я проверил поиском по каждому файлу.
