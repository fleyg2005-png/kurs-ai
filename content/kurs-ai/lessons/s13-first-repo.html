Репозиторий для сайта

Пять минут — и у вас есть пустая папка для сайта: публичный репозиторий hello-ai с одним файлом README. Файлы сайта в нём создаст агент в следующем уроке, руками вы ничего туда не кладёте. Войдите на github.com в соседней вкладке и идите по шагам.

Почему публичный

Бесплатный сайт на GitHub Pages делается только из публичного репозитория. Публичный значит, что любой человек может открыть и сайт, и все файлы в папке. Поэтому в hello-ai никогда не попадает ничего личного: ни телефона, ни адреса, ни паспортных данных, ни данных клиентов, ни паролей. Это же правило агент получит первым пунктом в своих правилах.

Справа вверху на любой странице GitHub есть кнопка ＋ (плюс со стрелкой). Нажмите её и выберите New repository (новый репозиторий).

Откроется страница Create a new repository. Заполните три вещи, остальное оставьте как есть:

  1. В поле Repository name введите hello-ai: латиницей, без пробелов. Это имя войдёт в адрес сайта.
  2. Выберите Public (публичный): без этого бесплатного сайта не будет.
  3. Поставьте галочку Add a README file. GitHub сам создаст файл README, обложку репозитория, и папка не будет пустой. Агенту удобнее начинать работу с непустой папки.

Больше в репозитории ничего не делайте: файлы руками не создавайте и не правьте. Страницу сайта и файлы правил для агента создаст сам агент по одному запросу в следующем уроке.

Имя занято? Если у вас уже есть репозиторий hello-ai, например после пути «Сайт: git руками», GitHub подсветит поле имени красным. Возьмите имя hello-ai-site и дальше в курсе подставляйте его вместо hello-ai, в том числе в адресе сайта.

Что внутри и что будет дальше

Сейчас в папке один файл. После первого запроса к агенту в уроке 14 репозиторий будет выглядеть так:

README.md — обложка репозитория, создал GitHub CLAUDE.md — правила для Claude Code, создаст агент AGENTS.md — те же правила для Codex и Copilot, создаст агент index.html — страница о вас, создаст агент

index.html — главный файл сайта: именно его покажет GitHub Pages по адресу username.github.io/hello-ai. CLAUDE.md и AGENTS.md — памятки, которые агент читает в начале каждой сессии: что можно, чего нельзя и как сохранять работу.

Проверьте себя

Почему репозиторий для сайта создаём публичным?

  • Публичный быстрее работает
  • Бесплатный GitHub Pages работает только для публичных репозиториев
  • Агент не видит приватные репозитории

На бесплатном тарифе Pages публикует только публичные репозитории. Цена этого: все файлы видят все, поэтому в репозиторий не кладём ничего личного.

Зачем ставить галочку Add a README file?

  • GitHub создаст первый файл, и агенту будет с чего начать работу
  • Без README не откроется сайт
  • README хранит пароль от репозитория

README — обложка репозитория. Сайт показывает другой файл, index.html, его создаст агент.

Кто создаст в репозитории страницу сайта и файлы правил?

  • Вы, через кнопку Add file
  • GitHub, автоматически после создания репозитория
  • Агент, по первому запросу в уроке 14

В этом пути файлы руками не создаём. Готовый запрос с текстами всех файлов будет в следующем уроке.
