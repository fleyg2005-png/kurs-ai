Окружение — это настройки облачной машины, в которой работает агент. На claude.ai/code, на экране новой сессии, под полем ввода первая кнопка — выбор окружения. По умолчанию там Default. Откройте её и внизу меню выберите New environment.

Рядом с полем ввода есть выбор режима, Mode:

  • Auto — Claude сам решает, что можно делать без вопросов;
  • Accept edits — сам принимает правки файлов, остальное спрашивает;
  • Plan — сначала план, потом изменения.

Выберите Auto: так агент доводит задачу до конца и сохраняет сам.

2. Делай сайт простыми файлами без сборки: HTML, CSS и JavaScript в корне репозитория, чтобы GitHub Pages показывал их сразу.
3. Не удаляй и не переписывай целиком то, что уже работает, без прямой просьбы.
4. Тексты на сайте пиши по-русски, если я не прошу иначе.

## Как сохранять работу
5. Git и GitHub — полностью твоя забота. Я не создаю ветки и pull request и ничего не нажимаю на GitHub.
6. Каждую задачу доводи до конца сам: создай ветку, сохрани изменения коммитом, открой pull request и сразу слей его в main. Если слить не получается, объясни мне простыми словами, что мешает.
7. В конце ответа коротко напиши: что сделано, какие файлы созданы или изменены и где лежит результат.
8. Если я прошу вернуть как было — найди прошлую версию в истории репозитория и так же сохрани её сам.
=====

Проверьте себя

Какой режим выбрать, чтобы агент довёл задачу до конца и сохранил её сам?

  • Plan
  • Accept edits
  • Auto

В Auto Claude сам решает, что можно делать без вопросов, и доводит задачу до сохранения. Accept edits спрашивает про всё, кроме правок файлов. Plan сначала показывает план.

Зачем окружение full вместо Default?

  • У full полный доступ в сеть, поэтому агент может скачать то, что нужно для задачи
  • В full агенту можно передавать пароли
  • Default не умеет работать с GitHub

У Default доступ Trusted: только магазины пакетов и GitHub. Ключи и пароли в чат не вставляем ни в каком окружении.

Какая строка первого запроса говорит агенту, что сохранять работу он должен сам?

  • «README.md не меняй»
  • «Ветки и pull request создавай сам и сразу сливай в main — я на GitHub ничего не нажимаю»
  • «Это репозиторий моего сайта на GitHub Pages»

Эта строка есть в первом запросе, а правила 5–8 закрепляют её в CLAUDE.md и AGENTS.md. В следующих задачах хватает фразы «Сохрани результат сам, как в правилах».

Как проверить, что первый запрос выполнен?

  • Открыть вкладку Pull requests и принять изменения
  • Прочитать отчёт агента и открыть репозиторий на GitHub: там CLAUDE.md, AGENTS.md и index.html
  • Дождаться письма от GitHub

Агент сам сохранил файлы в main. Ваша проверка — увидеть их в списке файлов и открыть правила.
