Агент прочитает ваши посты и выгрузку кампаний, перепишет README и сам сохранит его в репозиторий. Вы откроете результат, сверите его с постами и отправите одно замечание. На GitHub вы при этом ничего не нажимаете.

Что сейчас произойдёт

Вы: задача→ Агент читает посты→ Пишет README и сохраняет→ Отчёт: что сделано→ Вы: открыть и сверить→ Замечание → правка

Это цикл, который повторится в каждой задаче курса. Ваша часть — первая и две последние клетки. Всё, что между ними, включая сохранение, агент делает сам по правилам из CLAUDE.md.

Проверьте себя

Агент написал: «Сохранил в main: README.md». Что видят коллеги, у которых есть доступ к репозиторию, на главной странице?

  • Новый README: агент уже сохранил его в основную версию
  • Старый README, пока вы не нажмёте кнопку на GitHub
  • Пустую страницу, пока агент не закончит сессию

«Сохранил в main» значит: результат уже в репозитории. Подтверждать на GitHub ничего не нужно — поэтому проверка после сохранения так важна.

Что вы проверяете в первую очередь?

  • Правильность кода
  • Какие файлы агент изменил и верны ли факты в результате против содержимого постов
  • Сколько записей появилось в истории

Тронут только README — агент не вышел за рамки. Факты в таблице сверены с шапками постов — результат верный. Код здесь не писался, а когда будет писаться, проверять всё равно результат.

Где оставить замечание так, чтобы агент сам внёс правку?

  • Сообщением в ту же сессию на claude.ai/code
  • Исправить README руками через карандаш на GitHub
  • В письме в поддержку Anthropic

Сессия живёт и после сохранения. Агент исправит и снова сохранит сам, а контекст задачи у него уже есть.

После правки README стал хуже, чем был. Как вернуть прежнюю версию?

  • Никак: агент перезаписал файл
  • Восстановить текст по памяти и загрузить через Upload files
  • Написать агенту «верни README.md как было до последнего изменения» — он найдёт прошлую версию в истории и сохранит сам

Каждое сохранение — версия в истории. Возврат — тоже задача агенту, пункт 9 его правил.
