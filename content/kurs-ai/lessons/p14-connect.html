Подключить GitHub к Claude и ChatGPT

Репозиторий с карточками и отзывами есть. Теперь даём к нему доступ ИИ: три способа для Claude и один для ChatGPT, каждый — по шагам «нажал → увидел». В конце урока агент первым запросом создаст в репозитории правила, чеклист, шаблон ответа и контрольную карточку — и сам их сохранит. Вы откроете репозиторий и увидите новые файлы.

Два режима: дать почитать и дать поработать

Подключений несколько, и путаница начинается здесь. Разница простая.

В этом пути главный режим — второй, и главный инструмент — Claude Code. Первый режим пригодится для быстрых вопросов, когда программа не нужна.

Тарифы на октябрь 2026. Claude Code в браузере работает на Pro, Max и Team; на Free его нет. Codex в ChatGPT — на Plus, Pro и Business. Кнопка + → Add from GitHub в чате Claude доступна после подключения коннектора GitHub в настройках.

# Правила для ИИ-агента в этом репозитории

6. Git и GitHub — полностью твоя забота. Я не создаю ветки и pull request и ничего не нажимаю на GitHub.

Файл checklist.md в корне:
=== начало ===
# Чеклист карточки товара

1. **Название** — по формуле «тип + бренд + модель + главный признак»; понятно, что это за товар, без расшифровки.
2. **Описание** — от 500 знаков; написано для покупателя: что это, для кого, чем отличается.
3. **Характеристики** — заполнены габариты, материал, цвет; без пустых полей и прочерков.
4. **Комплектация** — перечислено всё, что лежит в коробке.
5. **Ключевые слова** — есть список запросов, по которым товар ищут.
6. **Цена и цена до скидки** — указаны обе; цена до скидки выше текущей.
7. **Остаток** — указан; если товара нет, это сказано прямо.
8. **Ответ на частый вопрос покупателя** — в карточке есть хотя бы один вопрос с ответом.
9. **Условия возврата** — сказано, как и в какой срок покупатель может вернуть товар.
10. **Описание не обещает лишнего** — каждое утверждение описания подтверждается характеристиками или комплектацией.
=== конец ===

Способ 2. Кнопка «+» в чате: дать почитать

Для вопросов по карточкам и отзывам без программ. Один раз подключаете коннектор, потом добавляете файлы в любой чат.

В claude.ai откройте настройки: Customize → Connectors, найдите GitHub и нажмите подключить. GitHub попросит войти и разрешить доступ — как в способе 1. Для приватного репозитория нужно то же приложение Claude GitHub App; если вы ставили его в шаге 3 способа 1, ничего делать не нужно.

Начните новый чат. В левом нижнем углу поля ввода нажмите + и выберите Add from GitHub.

Запрос к ИИ
Сверь приложенную карточку товара с чеклистом. Таблицей: пункт чеклиста — выполнено / не выполнено / неясно — цитата из карточки. Только из текста, ничего не додумывай.

Claude ответит в чате. В репозитории ничего не изменится — это режим «почитать».

Три ограничения режима «почитать». Claude видит только выбранные файлы и только их содержимое — не историю изменений. Файлы не обновляются сами: после изменений в репозитории выбирайте их заново. Приватный репозиторий открывается, только если на него установлено приложение Claude; если доступа нет, Claude покажет ссылку на его установку.

Способ 3. Файлы репозитория в проекте Claude

Если вы заводили проект в уроке 10, карточки и чеклист из репозитория можно положить прямо в его знания: в разделе знаний проекта нажмите + → GitHub → найдите репозиторий или вставьте адрес → выберите файлы и папки. Они будут видны во всех чатах проекта. Когда карточки в репозитории изменились, нажмите Sync — подтянется свежая версия; состав файлов меняется через Configure files. Это удобнее, чем добавлять файлы в каждый чат, но правило то же: выбирайте только нужное.

Способ 4. ChatGPT: Codex

Тот же режим «поработать», только у OpenAI. Нужен Plus, Pro или Business. Codex — запасной вариант: он тоже работает с репозиторием, но результат оставляет pull request'ом и сам его не сливает. Как с этим жить, не нажимая кнопок на GitHub, — в уроке 16. Первый запрос из способа 1 давайте Claude Code.

Перейдите на chatgpt.com/codex. В приложении тот же раздел: Codex → Work in → Cloud.

Нажмите Connect GitHub. GitHub предложит установить приложение Codex и спросит, какие репозитории открыть: Select repositories → shop. Приватный репозиторий открывается именно так — через выбор в приложении.

Select environment → Create environment → репозиторий shop → Get started. Codex сам осмотрит проект; у папки с карточками настраивать нечего. Проверьте и нажмите Publish.

Нажмите Start a new task, вставьте задачу только на чтение и отправьте. Задача выполняется в отдельной среде с копией репозитория; ответ появится в задаче.
