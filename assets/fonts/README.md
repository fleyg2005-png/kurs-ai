# Шрифты

Лежат в репозитории, чтобы сайт не зависел от внешних серверов и работал при открытии из файлов.

| Шрифт | Где используется | Лицензия |
|---|---|---|
| [Inter](https://rsms.me/inter/) (variable) | основной текст и интерфейс | SIL Open Font License 1.1 |
| [Onest](https://github.com/simpals/onest) (variable) | заголовки | SIL Open Font License 1.1 |
| [JetBrains Mono](https://www.jetbrains.com/lp/mono/) (variable) | код и адреса | SIL Open Font License 1.1 |

Файлы взяты из пакетов [Fontsource](https://fontsource.org) (`@fontsource-variable/*`), подмножества latin, latin-ext и cyrillic. Текст лицензии: https://openfontlicense.org
