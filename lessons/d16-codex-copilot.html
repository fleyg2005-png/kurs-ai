То же в ChatGPT (Codex) и Copilot

В прошлом уроке Claude Code переписал README репозитория contracts и прислал pull request. Теперь ту же задачу — слово в слово — получат два других агента: Codex в ChatGPT и облачный агент Copilot на GitHub. Выберите вкладку под свою подписку.

Одна задача — любой агент

Агенты различаются кнопками, а не языком общения. Задача описывает результат — что прочитать, что написать, чего не трогать, что положить в описание PR — и ничего не говорит о том, кто её выполняет. Поэтому текст из прошлого урока отдаём без единой правки:

Задача агенту — та же, что в прошлом уроке
Прочитай все файлы в репозитории. Ничего в документах не меняй.
Сделай две вещи:
1. Перепиши README.md: что лежит в репозитории, список договоров таблицей (файл — стороны — предмет — дата — срок действия; данные бери только из текста, если чего-то нет — ставь «не указано»).
2. В конце README предложи 3 задачи, которые ты можешь выполнить по этим документам автоматически, с оценкой: что получится на выходе.
Открой pull request и в его описании напиши, какие файлы ты прочитал и что в них непонятно.

README уже переписан Claude — это не мешает, а помогает: второй агент сделает то же по-своему, и вы впервые сравните два результата — у кого таблица полнее, кто честнее ставит «не указано». Понравился второй вариант — слейте его PR; первый лучше — закройте PR кнопкой Close pull request. Оба решения правильные, если приняты глядя на Files changed.

Общее у всех трёх агентов: задача выполняется в изолированной копии репозитория, агент может ставить библиотеки и запускать программы на Python, результат приходит как pull request, а сливаете вы его на GitHub.

Два агента — два пути

Нужен ChatGPT Plus ($20/мес), Pro или Business — на Free и Go агента нет. Откройте chatgpt.com/codex в соседней вкладке.

Перейдите на chatgpt.com/codex. В приложении ChatGPT тот же раздел: Codex → Work in → Cloud; на телефоне — раздел Codex.

Нажмите Connect GitHub. GitHub предложит установить приложение Codex на ваш аккаунт и спросит, какие репозитории ему открыть: Select repositories → contracts (или All repositories). Тот же принцип, что Claude GitHub App: приватный репозиторий агент видит только через своё приложение.

Select environment → Create environment → выберите contracts. Окружение создаётся один раз — дальше все задачи по этому репозиторию идут в нём.

Get started

Нажмите Get started. Codex сам изучает проект и ставит зависимости. В репозитории с документами программ пока нет, так что этап короткий.

Проверьте, что выбран нужный репозиторий, и нажмите Publish. Подтверждение Environment published — окружение готово.

Нажмите Start a new task, вставьте задачу из начала урока и отправьте. Обратите внимание: вы ничего не меняли в тексте.

Задача выполняется в изолированной среде с копией репозитория, обычно от 1 до 30 минут. Codex показывает изменённые файлы и логи команд: видно, как он читает папку contracts/. Изменённый файл должен быть один — README.md; если есть другие, агент нарушил условие «ничего в документах не меняй» — повод для замечания.

Вскоре Copilot создаст pull request и напишет в нём план в виде чеклиста, отмечая пункты по мере работы. Работает он в GitHub Actions — облачных машинах GitHub. Можно уйти: когда закончит, попросит у вас ревью.

Откройте PR → Files changed. Проверьте две вещи: изменён только README.md, а в таблице столько строк, сколько файлов в contracts/. У файла .md есть кнопка просмотра «как отрендерено» — таблицу так читать удобнее.

Нашли ошибку — наведите на строку в diff, нажмите «+» и напишите замечание: «Срок действия договора аренды указан в пункте 7.1 — 11 месяцев. Исправь „не указано“». Агент прочитает и пришлёт правку новыми коммитами в тот же PR. Проверьте снова.

Merge pull request → Confirm merge → Delete branch. Issue закроется, README на главной странице обновится. Версия Claude лучше — Close pull request: в репозитории ничего не изменится.

Проверьте себя

Какой тариф ChatGPT нужен для Codex?

  • Любой, включая Free
  • Go и выше
  • Plus, Pro или Business

На Free и Go Codex недоступен. Минимальный тариф с агентом — Plus за $20/мес.

Как запустить облачного агента Copilot?

  • Создать issue с задачей и назначить его на Copilot в блоке Assignees
  • Написать задачу в комментарии к последнему коммиту
  • Открыть README и нажать кнопку Copilot

Назначение issue на Copilot — и есть запуск. Агент сам создаст pull request с планом и попросит ревью.

Что нужно изменить в тексте задачи, переходя от Claude Code к Codex или Copilot?

  • Убрать пункт про pull request — другие агенты его не делают
  • Ничего: задача описывает результат и границы, а не исполнителя
  • Переписать на английский

Хорошая задача говорит, что прочитать, что сделать, чего не трогать и что написать в PR. Всё это одинаково для любого агента.

Codex закончил и показал изменённые файлы. Где принимается решение слить результат?

  • В окне Codex: там есть кнопка Merge
  • Слияние происходит само, когда задача завершена
  • На GitHub: Pull requests → Files changed → Merge pull request; или Close pull request, если результат не нужен

Codex показывает изменения и по просьбе открывает pull request. Приёмка и слияние — всегда на GitHub и всегда ваше решение.

Практика

Пройдите один из двух путей до pull request и сравните README второго агента с версией Claude: у кого таблица полнее, чьи три предложенные задачи вы бы поручили.

  • Я выбрал агента под свою подписку и дошёл по степперу до pull request.
  • Агент получил задачу слово в слово — ту же, что Claude Code в прошлом уроке.
  • В PR изменён только README.md; я открыл Files changed и сверил таблицу договоров с файлами в contracts/.
  • Если агент ошибся в таблице, я оставил замечание и получил правку в тот же PR.
  • PR от второго агента слит (Merge pull request → Confirm merge) или закрыт (Close pull request) — и я могу назвать одну причину своего решения.

Теперь вы умеете работать с любым из трёх агентов. Следующий урок — как проверять pull request и оставлять замечания так, чтобы агент понял с первого раза.
