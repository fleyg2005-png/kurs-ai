Восемь минут и один аккаунт, который станет вашим рабочим местом до конца курса. Откройте github.com/signup в соседней вкладке и идите по шагам.

Интерфейс GitHub только на английском. Это не помеха: все слова, которые встретятся в курсе, переведены по ходу. Если браузер предлагает перевести страницу — лучше откажитесь: названия кнопок в курсе даны по-английски, чтобы вы их узнавали.

В поле Email введите адрес почты. На него придёт код подтверждения, а потом — уведомления о том, что делает ИИ-агент в ваших проектах.

Совет. Если вы планируете использовать GitHub для работы, берите почту, которая останется с вами при смене работодателя. Поменять её потом можно, но зачем лишние движения.

Требование GitHub: либо 15 и больше символов, либо минимум 8, среди которых есть цифра и строчная буква. Удобный способ — три-четыре несвязанных слова: зелёный-чайник-пятница-17 легко запомнить и трудно подобрать.

Не используйте пароль от почты. GitHub-аккаунт скоро получит доступ к вашим проектам и к ИИ-агентам, которые пишут в них код. Лучше всего — менеджер паролей (встроенный в браузер подойдёт).

Самый важный шаг. Имя пользователя станет частью адресов: github.com/username и, главное, адреса вашего будущего сайта username.github.io.

  • Разрешены латинские буквы, цифры и дефис. Пробелов, точек и кириллицы нет.
  • Хорошо: ivan-petrov, anna-hr, petrov-law. Плохо: kotik2007, xXx_ivan_xXx — это увидят клиенты и коллеги.
  • Если имя занято, GitHub скажет сразу: Username is already taken. Добавьте фамилию, профессию или город.

В поле Your Country/Region выберите страну. Галочка про рассылку (Receive occasional product updates…) не обязательна. Нажмите Continue.

GitHub покажет проверку Verify your account: нужно, например, повернуть предмет в правильную сторону или выбрать картинку. Если не получилось с первого раза — просто повторите, попыток много. После — кнопка Create account.

GitHub требует от всех пользователей двухфакторную аутентификацию: при входе кроме пароля нужен код из приложения на телефоне. Сделайте это сейчас, чтобы не упереться в блокировку в середине курса.

  1. Поставьте на телефон приложение-аутентификатор: Google Authenticator, Microsoft Authenticator или Яндекс Ключ.

  2. На GitHub: аватар → Settings → слева Password and authentication → Enable two-factor authentication.

  3. Отсканируйте QR-код приложением, введите 6-значный код с телефона.

  4. Сохраните recovery codes (коды восстановления) в менеджер паролей. Это ваш запасной вход, если телефон потеряется.

Проверьте себя

Почему имя пользователя стоит выбирать аккуратно?

  • Его нельзя будет сменить никогда
  • Оно войдёт в адрес вашего сайта и будет видно клиентам и коллегам
  • От него зависит стоимость тарифа

Сменить username технически можно, но все старые ссылки на ваши проекты и сайт сломаются. Проще выбрать нормальное имя сразу.

Какой тариф GitHub нужен для курса?

  • Бесплатный (Free) — его хватает на всё, включая Codespaces и публикацию сайта
  • Pro — без него нельзя публиковать сайты
  • Team — нужен для работы с ИИ-агентами

Публичные репозитории, GitHub Pages, 120 core-часов Codespaces в месяц — всё это входит в бесплатный тариф.

Зачем сохранять recovery codes при включении 2FA?

  • Они нужны для оплаты
  • Это запасной способ войти, если телефон с приложением потерян
  • Их просит ИИ-агент при подключении

Без телефона и без кодов восстановления вернуть доступ к аккаунту очень долго и не всегда возможно.

Практика

  • Аккаунт создан, почта подтверждена, вы видите свой username справа вверху.
  • Двухфакторная аутентификация включена, recovery codes сохранены.
  • Settings → Public profile: заполнены имя (Name) и, по желанию, фото. Так ваши будущие pull request будут выглядеть по-человечески.
  • Вы вышли (Sign out) и вошли снова — убедились, что пароль и 2FA работают.

Есть аккаунт. Теперь у вас есть место, где будут жить ваши проекты и где ИИ-агенты будут для вас работать. В следующем уроке — первый репозиторий и первый коммит.
