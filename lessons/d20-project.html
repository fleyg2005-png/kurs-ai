Проект: проверка договоров по чеклисту

За час-полтора у вас появится первый инструмент: программа, которая проверяет каждый договор из репозитория по вашему чеклисту и собирает сводную таблицу сроков и штрафов. Программу пишет и запускает агент. Вы ставите задачу, читаете отчёты и принимаете pull request.

Что понадобится. Аккаунт Claude на Pro, Max или Team; приватный репозиторий contracts, к которому подключено Claude GitHub App (урок d14); 3–5 обезличенных договоров в папке contracts/, файл checklist.md и шаблон templates/pretenziya.md. Сколько это стоит

Сессия агента расходует лимиты тарифа — те же скользящие 5-часовые окна и недельный лимит, что и чат. Одна задача вроде этой — десятки обращений к модели, поэтому стоит заметно больше одного вопроса в чате; точных чисел курс не называет, они меняются. Виртуальная машина агента отдельно не оплачивается. Для нескольких таких задач в неделю достаточно Pro ($20/мес, $17/мес при годовой оплате); Max — если инструментов будет много.

Если агент говорит, что не смог прочитать .docx

Бывает: библиотека не справилась с конкретным файлом, документ сохранён в старом формате, внутри — картинка вместо текста. Не пытайтесь чинить сами.
