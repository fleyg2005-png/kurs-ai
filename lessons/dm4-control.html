Контрольная 4: GitHub подключён к ИИ

Без подсказок и степперов: создайте второй приватный репозиторий с документами, откройте его ИИ-агенту и получите первый ответ, не изменив в репозитории ни одного файла. Всё это вы делали в уроках модуля.

Задание

  1. Создайте новый приватный репозиторий с README. Имя — под свою профессию, латиницей: templates-hr, accounting-docs, tenders.
  2. Положите в него 2–3 обезличенных документа — регламент, шаблон приказа, типовой договор — через Upload files или Create new file.
  3. Откройте репозиторий агенту — Claude Code или Codex. Claude Code: установите Claude GitHub App на этот репозиторий (github.com/apps/claude/installations/new → аккаунт → репозиторий) и выберите его в селекторе на claude.ai/code. Codex: на chatgpt.com/codex откройте репозиторий приложению Codex, создайте окружение, нажмите Publish.
  4. Дайте тестовую задачу и дождитесь ответа в сессии:
    Задача агенту
    Перечисли файлы репозитория и кратко опиши каждый: что это за документ и о чём он. Ничего не меняй: не создавай и не правь файлы, не делай коммитов и pull request. Ответь списком здесь.
  5. Дополнительно: в обычном чате Claude нажмите + слева внизу поля ввода → Add from GitHub → этот репозиторий → один файл → задайте по нему вопрос: «Какие сроки указаны в этом документе?».

Критерии приёмки

Отмечайте только то, что проверили своими глазами. Чеклист и квиз ниже засчитывают контрольную автоматически.

  • Репозиторий существует, рядом с именем значок Private, в нём README и 2–3 документа без ФИО, ИНН, адресов и телефонов.
  • Репозиторий виден в селекторе репозиториев на claude.ai/code — или для него опубликовано окружение Codex.
  • Агент ответил списком всех файлов с описанием каждого, и список совпадает с тем, что я вижу на github.com.
  • После ответа агента в репозитории ничего не изменилось: во вкладке Pull requests пусто, число коммитов прежнее.
  • В обычном чате Claude я добавил файл через + → Add from GitHub и получил ответ по его содержимому.
  • Я могу объяснить одной фразой, чем «дать почитать» (+ в чате, проект) отличается от «дать поработать» (Claude Code, Codex).
  • Я знаю, какая подписка нужна агенту и что GitHub при этом остаётся бесплатным.

Проверка понимания

Зачем агенту репозиторий, если документ можно вставить в чат?

  • В чат нельзя вставить документ длиннее одной страницы
  • Агент работает с файлами, а не с текстом в окне: читает документы из репозитория, запускает программу, сохраняет результат и показывает изменения в pull request
  • Репозиторий нужен только для оплаты подписки

В чате агенту некуда положить программу и отчёты. Репозиторий — его рабочая папка с историей и приёмкой.

Вы создали приватный репозиторий, но в селекторе на claude.ai/code его нет. Самая вероятная причина?

  • Репозиторий должен быть публичным
  • Нужен тариф Max
  • На этот репозиторий не установлено Claude GitHub App

Публичные репозитории доступны сразу после Sign in with GitHub, приватные — только после установки Claude GitHub App с выбором аккаунта и репозитория.

Чем «+ → Add from GitHub» в чате отличается от задачи в Claude Code?

  • Через + Claude читает выбранные файлы и отвечает в чате, ничего не меняя; Claude Code работает в копии репозитория, меняет файлы, делает коммиты и pull request
  • Через + Claude видит ещё и историю, pull request и issues
  • Разницы нет — это один и тот же инструмент в двух местах

«Дать почитать» — + в чате и проект — ничего в репозитории не меняет. «Дать поработать» — Claude Code: своя машина, коммиты, PR.

Что видит Claude, когда вы добавили файлы через +?

  • Весь репозиторий целиком, включая историю коммитов
  • Имена и содержимое выбранных файлов; после изменений в репозитории их нужно выбрать заново
  • Только имена файлов, без содержимого

Claude видит ровно то, что вы отметили в файловом браузере: не историю, не PR, не issues. Автоматически не обновляется.

Что из этого платное?

  • Приватные репозитории на GitHub
  • Установка Claude GitHub App
  • Сам агент: Claude Code нужен тариф Pro, Max или Team; Codex — Plus, Pro или Business

GitHub с приватными репозиториями бесплатен, приложение тоже. На бесплатных тарифах Claude и ChatGPT агентов нет.

Если не получается

Репозитория нет в селекторе

Claude Code: репозиторий приватный, а Claude GitHub App на него не установлено — откройте github.com/apps/claude/installations/new, выберите аккаунт и репозиторий, вернитесь и обновите список. Codex: новый репозиторий должен быть в списке репозиториев, открытых приложению Codex; затем создайте окружение.

Агент пишет, что документов нет

Агент видит только то, что лежит в репозитории на GitHub, а не на вашем компьютере. Если на github.com файлов нет в списке — загрузка не завершена кнопкой Commit changes. Проверьте и ветку в селекторе: main.

Add from GitHub не показывает репозиторий

GitHub должен быть подключён в коннекторах: Customize → Connectors → GitHub. Для приватного репозитория без приложения Claude появится ссылка на его установку — установите и повторите. Адрес репозитория можно вставить в строку поиска.

Если причина непонятна — не угадывайте, спросите ИИ. Готовый запрос:

Запрос к ИИ
Я подключаю приватный репозиторий GitHub к Claude Code (claude.ai/code).
Репозиторий: https://github.com/USERNAME/templates-hr, приватный, в нём README.md и три файла .docx.
Я вошёл через Sign in with GitHub и нажал Authorize.
Проблема: [репозитория нет в селекторе под полем ввода / репозиторий есть, но агент пишет, что файлов нет].
Claude GitHub App я [установил на все репозитории / установил только на другой репозиторий / не устанавливал].
Назови 3 самые вероятные причины по убыванию вероятности и для каждой — проверку за минуту, без установки программ.

Сдали? Значит, у ИИ есть ваша рабочая папка и доступ к ней. Дальше — модуль 5: первая настоящая задача, в которой агент сам делает коммит и pull request.
