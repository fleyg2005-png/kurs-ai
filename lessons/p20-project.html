Проект: проверка карточек товаров по чеклисту

За час-полтора у вас появится первый инструмент: программа, которая проверяет каждую карточку товара по вашему чеклисту и собирает сводную таблицу с ценами, остатками и оценками. Пишет и запускает её агент; вы ставите задачу, читаете отчёты и принимаете pull request.

Что понадобится. Аккаунт Claude на Pro, Max или Team; приватный репозиторий shop, к которому подключено Claude GitHub App (урок 14); 4–5 карточек в папке tovary/, файл checklist.md, выгрузка otzyvy/otzyvy.csv и шаблон templates/otvet-na-otzyv.md. Create PR

Нажмите Create PR. Агент создаст pull request с заголовком и описанием: что сделано, что не получилось, как проверить за 5 минут — вы просили об этом в ТЗ. Сессия остаётся живой: замечания после этого попадут в тот же PR. Откройте ссылку.

В PR откройте Files changed и найдите reports/termokruzhka.md. У .md-файлов GitHub показывает кнопку просмотра в отрендеренном виде — нажмите, чтобы увидеть таблицу вместо зелёных строк. Выберите три строки: «Цена и цена до скидки», «Остаток» и любую «не выполнено». Откройте карточку tovary/termokruzhka.md — она читается в браузере — и сверьте: цитата есть дословно, значение взято из нужной строки, «не выполнено» в карточке действительно нет.

Сколько это стоит

Сессия агента расходует лимиты тарифа — те же скользящие 5-часовые окна и недельный лимит, что и чат; одна такая задача — десятки обращений к модели, то есть заметно больше вопроса в чате (точных чисел курс не называет). Виртуальная машина отдельно не оплачивается. Для нескольких задач в неделю достаточно Pro ($20/мес); Max — если инструментов много.

Если агент говорит, что не смог разобрать выгрузку

Причины разные: Excel сохранил CSV с другим разделителем, редкая кодировка, лишние строки-заголовки, оценка записана словом. Не чините сами. Два пути: попросить агента определить формат самостоятельно или выгрузить отзывы заново и загрузить файл через Upload files. Строки, которые прочитать нельзя, агент должен перечислить, а не пропустить молча — и не заполнять «по памяти».
