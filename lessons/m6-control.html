Контрольная 6: задача агенту и ревью

Без подсказок и степперов: сделайте сами полный цикл — ТЗ, агент, ревью с замечаниями, слитый PR и обновлённый сайт. Всё это вы уже делали в уроках 19–22, теперь — на новой задаче и с настоящим ревью.

Задание

  1. Выберите любого агента: Claude Code в браузере, Codex, Copilot cloud agent или бесплатно — Copilot в режиме Agent в Codespaces.
  2. Напишите по шаблону урока 19 ТЗ на новую функцию для hello-ai. Варианты на выбор: раздел «Контакты» с формой (имя, почта, сообщение), которая при нажатии кнопки показывает надпись «Спасибо, сообщение получено» и никуда ничего не отправляет; переключатель тёмной темы, который запоминает выбор; калькулятор для своей профессии — отпускных, НДС, госпошлины. Калькулятор пени не подходит — он уже сделан.
  3. Запустите агента и дождитесь ветки с pull request. Если агент внутри Codespaces — ветку и PR создайте сами.
  4. Проведите ревью по чеклисту урока 22. Оставьте минимум два замечания — к строке diff или в комментариях PR — и добейтесь, чтобы агент их исправил.
  5. Слейте PR и убедитесь, что сайт обновился и функция работает по примеру из вашего ТЗ.
  6. Запишите в README.md одну строку о новой функции — руками через карандаш или отдельной задачей агенту.

Критерии приёмки

Отмечайте только то, что проверили своими глазами. Чеклист и квиз ниже засчитывают контрольную автоматически.

  • Моё ТЗ содержит все шесть частей: цель, где, поведение с примером, критерии готовности, чего не трогать, ограничения.
  • PR сделан из отдельной ветки, а не коммитом в main; в описании PR понятно, что изменилось и зачем.
  • В PR есть минимум два моих замечания и после них — новые изменения агента, в которых замечания учтены.
  • Во вкладке Files changed тронуты только файлы, разрешённые в ТЗ.
  • В коде нет ключей, паролей, личных данных и загрузки скриптов с чужих сайтов — я проверил по чеклисту урока 22.
  • PR слит через Merge pull request → Confirm merge, и сайт в режиме инкогнито показывает новую функцию; пример из ТЗ даёт ожидаемый результат.
  • В README.md появилась строка о новой функции, и этот коммит виден в истории.

Проверка понимания

Чем ИИ-агент отличается от чата с ИИ?

  • Агент отвечает быстрее и длиннее
  • Агент сам читает и меняет файлы в репозитории, запускает проверки и исправляет ошибки, пока задача не решена
  • Агент не требует репозитория и работает с любым текстом

Чат выдаёт текст, который вы переносите руками. Агент действует в проекте и присылает результат веткой с pull request.

В каком режиме Claude Code правит файлы и пушит ветку, не спрашивая разрешения на каждую правку?

  • Accept edits
  • Plan
  • Auto

Plan сначала показывает план и ждёт одобрения, Auto пропускает действия через автоматический классификатор. Без вопросов работает Accept edits.

Что нужно, чтобы назначить issue на Copilot и получить от него pull request?

  • Любой аккаунт GitHub, это бесплатно для всех
  • Подписка ChatGPT Plus
  • Copilot Pro ($10/мес) или выше; бесплатно — студентам, преподавателям и мейнтейнерам

Облачный агент Copilot входит только в Copilot Pro и выше. На Copilot Free есть режим Agent внутри редактора, но не облачный агент.

Как работать с агентом без единой платной подписки?

  • Никак: все агенты платные
  • Открыть репозиторий в Codespaces и включить в Copilot Chat режим Agent; ветку, коммит и PR сделать самому
  • Использовать Claude Code на тарифе Free

Codespaces даёт 120 core-часов в месяц, Copilot Free — режим Agent с лимитами. Claude Code и Codex на бесплатных тарифах недоступны.

Что проверить в PR от агента в первую очередь, не читая код?

  • Список тронутых файлов и результат на сайте по примеру из ТЗ
  • Количество строк кода: чем больше, тем лучше сделано
  • Время, за которое агент справился

Лишние файлы и несовпадение с примером из ТЗ видны без знания языка программирования. Объём кода и скорость ни о чём не говорят.

Какая из ситуаций — красный флаг, при котором PR сливать нельзя?

  • Агент добавил к результату знак ₽, хотя в ТЗ этого не было
  • Агент вынес стили в отдельный файл style.css
  • Агент вставил в index.html ключ API, чтобы подгружать курс валют с внешнего сервиса

Ключ на публичном сайте увидит любой, а внешнего сервиса в ТЗ не было. Первые два случая — повод для замечания или вопроса, но не опасность.

Если не получается

Агент не видит репозиторий или не запускается

Claude Code: нужен Pro, Max или Team; приватный репозиторий требует Claude GitHub App. Codex: не подключён GitHub или окружение не опубликовано (Publish). Copilot cloud agent: нет Copilot Pro. Если упёрлись — переключитесь на бесплатный путь из урока 21: контрольная засчитывается с любым агентом.

Агент сделал не то или тронул лишнее

Не сливайте. Напишите замечание с конкретикой: какой файл, какая строка, что ожидали. Если результат далёк от ТЗ целиком — закройте PR, уточните ТЗ (чаще всего не хватает примера и «чего не трогать») и запустите задачу заново.

PR слит, а сайт не изменился

Подождите 1–10 минут и обновите страницу с очисткой кеша. Проверьте, что PR слит именно в main и что в Settings → Pages по-прежнему выбрана ветка main. Откройте index.html в репозитории: если новой функции там нет, PR слит не туда.

Если причина непонятна — не угадывайте, спросите ИИ. Готовый запрос:

Запрос к ИИ
Я поставил задачу ИИ-агенту в репозитории https://github.com/USERNAME/hello-ai (публичный, сайт на GitHub Pages).
Агент: [Claude Code в браузере / Codex / Copilot cloud agent / Copilot в Codespaces].
Моё ТЗ: [вставьте текст ТЗ целиком].
Что сделал агент: [опишите: какие файлы изменены, что написал в ответе или в описании PR].
Что не так: [опишите, что вижу и что ожидал; если есть ошибка — её точный текст].
Назови 3 самые вероятные причины в порядке вероятности, для каждой — как проверить за минуту, и предложи текст замечания агенту, которое исправит ситуацию.

Сдали? Значит, вы прошли полный цикл заказчика: поставили задачу, добились исправлений и опубликовали результат, не написав ни строки кода. Последний модуль — инструмент для вашей профессии по этой же схеме.
