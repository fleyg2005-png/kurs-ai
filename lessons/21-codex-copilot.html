Codex и Copilot

Та же задача, то же ТЗ — другие агенты. Три пути: Codex от OpenAI, облачный агент Copilot прямо на GitHub и бесплатный вариант без единой подписки. Выберите вкладку под свою ситуацию.

Одно ТЗ для всех

Агенты различаются кнопками, а не языком общения. ТЗ из урока 19 подходит любому из них без изменений: цель, место, поведение с примером, критерии готовности, границы. Если калькулятор пени уже сделан Claude Code в уроке 20 — дайте новому агенту доработку, например кнопку «Очистить», но саму структуру ТЗ сохраните.

Запрос к агенту — тот же, что в уроке 20
Задача: добавь на главную страницу сайта (файл index.html) раздел «Калькулятор пени».

Цель: посетитель вводит сумму долга, ставку и срок просрочки и сразу видит сумму пени и формулу расчёта.

Где: index.html, новый раздел в конце страницы, перед закрывающим </body>. Стили и скрипт — внутри этого же файла.

Поведение:
— три поля ввода: «Сумма долга, ₽», «Ставка, % в день», «Дней просрочки»;
— кнопка «Рассчитать»;
— под кнопкой появляется результат: сумма пени с двумя знаками после запятой и формула словами: сумма × ставка / 100 × дни;
— если поле пустое или число отрицательное, показывай надпись «Проверьте введённые значения» и ничего не считай.
Пример: 100 000 ₽, 0,1 % в день, 30 дней → 3 000,00 ₽.

Критерии готовности:
— пример выше даёт 3 000,00 ₽;
— при пустом или отрицательном поле виден текст ошибки, а результата нет;
— раздел нормально выглядит на телефоне.

Не трогай: остальные разделы страницы, README.md и другие файлы.

Ограничения: без внешних библиотек и загрузки скриптов с других сайтов; весь текст интерфейса на русском; все изменения — только в index.html.

Когда закончишь, напиши коротко: что изменил и как мне проверить результат на сайте.

Три пути

Нужен ChatGPT Plus ($20/мес), Pro или Business — на Free и Go агента нет. Откройте chatgpt.com/codex в соседней вкладке.

Перейдите на chatgpt.com/codex. В приложении ChatGPT тот же раздел: Codex → Work in → Cloud; на телефоне — раздел Codex.

Нажмите Connect GitHub. GitHub предложит установить приложение Codex на ваш аккаунт и спросит, какие репозитории открыть: Select repositories → hello-ai или All repositories. Для курса достаточно одного.

Select environment → Create environment → выберите репозиторий hello-ai. Окружение создаётся один раз на репозиторий, дальше все задачи идут в нём.

Get started

Нажмите Get started. Codex сам изучает проект и ставит нужные зависимости. У сайта из одного файла зависимостей нет, так что этап короткий.

Проверьте, что выбран нужный репозиторий, и нажмите Publish. Появится подтверждение Environment published — окружение готово.

Нажмите Start a new task, вставьте ТЗ, приведённое выше, и отправьте. Обратите внимание: вы ничего не меняли в тексте — ТЗ одинаковое для любого агента.

Задача выполняется в отдельной изолированной среде с копией репозитория, обычно от 1 до 30 минут. Codex показывает изменённые файлы, логи команд и результаты проверок. Проверьте список файлов: должен быть один — index.html.

Задача: добавь на главную страницу сайта (файл index.html) раздел «Калькулятор пени»…

Через минуту-другую Copilot создаст pull request и напишет в нём план в виде чеклиста, отмечая пункты по мере работы. Работает он в GitHub Actions — облачных машинах GitHub. Можно уйти: когда закончит, пришлёт уведомление и попросит ревью.

Откройте PR → Files changed. Проверьте, что тронут только index.html и что сделано то, что просили в ТЗ.

Нашли, что поправить, — оставьте комментарий к строке в diff, как в уроке 17. Агент прочитает замечания и пришлёт правки новыми коммитами в тот же PR. Проверьте снова.

Merge pull request → Confirm merge → Delete branch. Issue закроется, а сайт обновится через 1–10 минут.

Ни одной подписки: Codespaces из урока 16 плюс Copilot Free в режиме агента. Агент работает внутри редактора — правит файлы и запускает команды с вашего подтверждения, — а ветку, коммит и PR делаете вы. Лимиты Copilot Free: ограниченный чат и до 2000 автодополнений в месяц; Codespaces — 120 core-часов в месяц.

В hello-ai нажмите кнопку с именем ветки main → введите penalty-calc → Create branch penalty-calc from main. Агент будет работать в этой ветке, а не в main.

Зелёная кнопка Code → вкладка Codespaces → Create codespace on penalty-calc (кнопка называется по текущей ветке). Через минуту откроется редактор.

Откройте панель Copilot Chat и переключите режим на Agent. Если Copilot на аккаунте ещё не включён, редактор предложит подключить его — выбирайте бесплатный Copilot Free.

Проверьте себя

Какой тариф ChatGPT нужен для Codex?

  • Любой, включая Free
  • Go и выше
  • Plus, Pro или Business

На Free и Go Codex недоступен. Минимальный тариф с агентом — Plus за $20/мес.

Как запустить облачного агента Copilot?

  • Создать issue с ТЗ и назначить его на Copilot в блоке Assignees
  • Написать задачу в комментарии к любому коммиту
  • Открыть Codespaces и нажать Run

Назначение issue на Copilot — и есть запуск. Агент сам создаст pull request с планом и попросит ревью.

Где выполняется работа Copilot cloud agent?

  • На вашем компьютере, в фоне браузера
  • В GitHub Actions — облачных машинах GitHub
  • В вашем codespace, пока он запущен

Облачный агент не зависит ни от вашего компьютера, ни от codespace: он работает в GitHub Actions и присылает результат в PR.

Чем бесплатный путь отличается от трёх облачных агентов?

  • Он не умеет править файлы, только подсказывает
  • Агент работает внутри редактора в Codespaces, а ветку, коммит и PR вы делаете сами
  • Он доступен только студентам

Copilot Free в режиме Agent правит файлы и запускает команды с вашего подтверждения, но за публикацию изменений отвечаете вы. Лимиты есть, но на учебные задачи хватает.
