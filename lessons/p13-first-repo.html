Репозиторий с карточками товаров для ИИ

Восемь минут — и у вас есть приватный репозиторий shop: чеклист карточки товара, шаблон ответа на отзыв, несколько карточек и выгрузка отзывов. В следующем уроке к нему подключится ИИ, в модуле 5 — начнёт в нём работать. Войдите на github.com в соседней вкладке и идите по шагам.

Commit changes — это просто «сохранить»

Каждое нажатие Commit changes создавало коммит — сохранённую порцию изменений с подписью, которую вы видите в истории. Ничего больше за этим словом нет: «сохранить файлы и подписать, что сделано». Подпись годится любая понятная.

Это единственное место в курсе, где вы коммитите сами. С модуля 5 коммиты в shop делает агент: получает задачу, пишет программу, запускает её на карточках и отзывах и сохраняет результат с подписью и ссылкой на свою сессию. Ваши кнопки с этого момента — Merge pull request и, если что-то пошло не так, Revert.

Почему Private и что это значит для агента

Приватный репозиторий видят только вы и те, кого вы добавили. Для рабочих файлов магазина — цен, остатков, текстов карточек — единственный разумный выбор. Следствие: ИИ-агенту он тоже не виден, пока вы не дадите доступ. Публичные репозитории Claude Code видит сразу после входа через GitHub, а для приватного нужно установить приложение Claude GitHub App и выбрать в нём ваш аккаунт и репозиторий shop; у Codex для этого своё приложение. Как это сделать — в следующем уроке.

Private не отменяет правила про персональные данные. Файлы будет читать агент на своей облачной машине. Карточки, цены и остатки можно загружать как есть, а персональные данные покупателей — нет: настоящие имена, телефоны, адреса. Перед загрузкой пройдитесь поиском по выгрузке отзывов.

Проверьте себя

Почему репозиторий shop сделан приватным?

  • Приватные репозитории агент обрабатывает быстрее
  • Публичные репозитории на бесплатном тарифе недоступны
  • В нём цены, остатки и тексты карточек: приватный репозиторий видят только вы и те, кого вы добавили, а агенту доступ даётся отдельно через приложение

И публичные, и приватные репозитории бесплатны. Разница — кто видит файлы: публичный — все, приватный — только вы и те, кому открыт доступ.

Что делает кнопка Commit changes при загрузке карточек и отзывов?

  • Отправляет файлы ИИ-агенту на проверку
  • Сохраняет файлы в репозиторий и записывает это в историю как коммит с подписью
  • Публикует карточки на маркетплейсе

Здесь коммит — просто «сохранить с подписью». С маркетплейсом репозиторий не связан: это ваша подготовительная кухня, а коммиты дальше будет делать агент.

Как в репозитории появилась папка templates?

  • В имени файла при создании был указан путь templates/otvet-na-otzyv.md — косая черта создала папку
  • Через кнопку New folder в меню Add file
  • Папки в репозитории может создавать только ИИ-агент

Папка появляется вместе с первым файлом, у которого в имени указан путь. Второй способ — перетащить папку целиком в Upload files, как вы сделали с tovary и otzyvy.
