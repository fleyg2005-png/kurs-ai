Контрольная 4: GitHub подключён к ИИ

Без подсказок и степперов: доведите приватный репозиторий shop до полного состава, добавьте карточку через Upload files, откройте репозиторий ИИ-агенту и получите от него первый ответ — без единого изменения с его стороны. Всё это вы делали в уроках модуля.

Задание

  1. Проверьте репозиторий shop из урока 13: он приватный, в корне README.md и checklist.md, в tovary/ — карточки товаров, в otzyvy/ — otzyvy.csv, в templates/ — шаблон ответа на отзыв. Чего не хватает — добавьте сейчас, уже без степпера.
  2. Добавьте в tovary/ ещё одну карточку — свой товар или, например, бутылку для воды: текст попросите у ИИ по образцу урока 13, сохраните на компьютере файлом butylka.md. Откройте папку tovary на GitHub → Add file → Upload files → перетащите файл → Commit changes.
  3. Откройте репозиторий агенту — Claude Code или Codex. Claude Code: установите Claude GitHub App на этот репозиторий (github.com/apps/claude/installations/new → аккаунт → репозиторий) и выберите его в селекторе на claude.ai/code. Codex: на chatgpt.com/codex откройте репозиторий приложению Codex, создайте окружение, нажмите Publish.
  4. Дайте тестовую задачу и дождитесь ответа в сессии:
    Задача агенту
    Перечисли файлы репозитория и кратко опиши каждый: что это за файл и что в нём. Ничего не меняй: не создавай и не правь файлы, не делай коммитов и pull request. Ответь списком здесь.
  5. Дополнительно: в обычном чате Claude нажмите + слева внизу поля ввода → Add from GitHub → этот репозиторий → одна карточка → задайте по ней вопрос: «Какая в карточке цена, цена до скидки и остаток?». Вместо чата можно добавить карточку в знания проекта: + → GitHub.

Критерии приёмки

Отмечайте только то, что проверили своими глазами. Чеклист и квиз ниже засчитывают контрольную автоматически.

  • Репозиторий shop существует, рядом с именем значок Private; в корне README.md и checklist.md, в tovary/ — 4–5 карточек, в otzyvy/ — otzyvy.csv, в templates/ — otvet-na-otzyv.md.
  • Новая карточка загружена через Upload files: файл открывается в tovary/, а в истории есть мой коммит загрузки.
  • Ни в одном файле нет реальных артикулов, брендов-клиентов, имён покупателей и закупочных цен.
  • Репозиторий виден в селекторе репозиториев на claude.ai/code — или для него опубликовано окружение Codex.
  • Агент ответил списком всех файлов с описанием каждого, и список совпадает с тем, что я вижу на github.com.
  • После ответа агента в репозитории ничего не изменилось: во вкладке Pull requests пусто, число коммитов прежнее.
  • В обычном чате Claude я добавил карточку через + → Add from GitHub (или в знания проекта через + → GitHub) и получил ответ по её содержимому.
  • Я могу объяснить одной фразой, чем «дать почитать» (+ в чате, проект) отличается от «дать поработать» (Claude Code, Codex).

Проверка понимания

Зачем агенту репозиторий, если карточку товара можно вставить в чат?

  • В чат нельзя вставить карточку длиннее одной страницы
  • Агент работает с файлами, а не с текстом в окне: читает карточки и отзывы из репозитория, запускает программу, сохраняет результат и показывает изменения в pull request
  • Репозиторий нужен только для оплаты подписки

В чате агенту некуда положить программу и отчёты. Репозиторий — его рабочая папка с историей и приёмкой.

Почему репозиторий shop приватный — и как тогда агент его видит?

  • Приватный репозиторий видят только вы и те, кого вы добавили; агенту доступ даёт приложение — Claude GitHub App или приложение Codex
  • Приватность включает шифрование, которое агент умеет снимать
  • Приватный репозиторий агент видит автоматически после любой авторизации

Private прячет цены, остатки и тексты карточек от посторонних — и от агента тоже, пока вы не установите приложение на этот репозиторий.

Вы загрузили butylka.md через Upload files и нажали Commit changes. Что произошло?

  • Карточка появилась в кабинете маркетплейса
  • Файл сохранился в репозитории, в истории появился ещё один коммит с моей подписью
  • Создался pull request, который нужно слить

Upload files и Commit changes — просто «сохранить файлы с подписью». Pull request присылает агент, а с кабинетом маркетплейса репозиторий не связан.

Вы создали приватный репозиторий, но в селекторе на claude.ai/code его нет. Самая вероятная причина?

  • Репозиторий должен быть публичным
  • Нужен тариф Max
  • На этот репозиторий не установлено Claude GitHub App

Публичные репозитории доступны сразу после Sign in with GitHub, приватные — только после установки Claude GitHub App.

Чем «+ → Add from GitHub» в чате отличается от задачи в Claude Code?

  • Через + Claude читает выбранные файлы и отвечает в чате, ничего не меняя; Claude Code работает в копии репозитория, меняет файлы, делает коммиты и pull request
  • Через + Claude видит ещё и историю, pull request и issues
  • Разницы нет — это один и тот же инструмент в двух местах

«Дать почитать» — + в чате и знания проекта: Claude видит только выбранные файлы, и после изменений их выбирают заново. «Дать поработать» — Claude Code и Codex: своя машина, коммиты, PR.

Если не получается

Репозитория нет в селекторе

Claude Code: репозиторий приватный, а Claude GitHub App на него не установлено — откройте github.com/apps/claude/installations/new, выберите аккаунт и репозиторий, вернитесь и обновите список. Codex: репозиторий должен быть в списке репозиториев, открытых приложению Codex; затем создайте окружение.

Агент пишет, что карточек нет

Агент видит только то, что лежит в репозитории на GitHub, а не на вашем компьютере. Если на github.com файлов нет в списке — загрузка не завершена кнопкой Commit changes. Проверьте и ветку в селекторе: main.

Add from GitHub не показывает репозиторий

GitHub должен быть подключён в коннекторах: Customize → Connectors → GitHub. Для приватного репозитория без приложения Claude появится ссылка на его установку — установите и повторите. Адрес репозитория можно вставить в строку поиска.

Если причина непонятна — не угадывайте, спросите ИИ. Готовый запрос:

Запрос к ИИ
Я подключаю приватный репозиторий GitHub к Claude Code (claude.ai/code).
Репозиторий: https://github.com/USERNAME/shop, приватный: README.md, checklist.md, папки tovary (карточки товаров .md), otzyvy (otzyvy.csv) и templates.
Вошёл через Sign in with GitHub, нажал Authorize.
Проблема: [репозитория нет в селекторе / репозиторий есть, но агент пишет, что файлов нет].
Claude GitHub App я [установил на все репозитории / только на другой репозиторий / не устанавливал].
Назови 3 самые вероятные причины по убыванию вероятности и для каждой — проверку за минуту, без установки программ.
