Как устроен курс

Регистрация на GitHub, первый репозиторий, запуск агента — пошаговые сценарии с экранами «что вы должны увидеть».

Ничего не устанавливаем

Никаких «скачайте и настройте». GitHub, редактор кода, терминал и ИИ-агенты — всё работает во вкладке браузера.

Частые вопросы

Это бесплатно?

Курс — да. Инструменты: GitHub бесплатен (включая Codespaces и GitHub Pages в разумных лимитах). У Claude и ChatGPT есть бесплатные тарифы, но ИИ-агенты (Claude Code, Codex) требуют платной подписки — порядка $20 в месяц. В курсе указано, где какой тариф нужен, и есть бесплатные обходные пути.

Claude и ChatGPT официально недоступны в России. Что делать?

Это правда: обоим сервисам нужен зарубежный номер телефона и карта, либо доступ через сервис-посредник. Курс не привязан к конкретному способу доступа — приёмы работают одинаково в любом интерфейсе, включая российские ассистенты. GitHub работает без ограничений.

Чем отличаются пути?

Общая часть одинаковая. В пути «Сайт» вы сами заводите репозиторий, делаете коммиты и pull request в браузере, публикуете инструмент на GitHub Pages и получаете ссылку, которую можно отправить коллегам. Пути «Юрист», «Маркетплейсы» и «Маркетолог» устроены одинаково: репозиторий — папка с файлами вашей работы, а весь git делает ИИ — вы ставите задачу, он пишет и запускает программу, присылает pull request, вы проверяете и принимаете. Отличается материал: у юриста — договоры и претензии, у менеджера маркетплейсов — карточки товаров и отзывы, у маркетолога — посты и отчёты по кампаниям. Можно пройти несколько путей: прогресс по урокам сохраняется.

Я совсем не технический человек. Справлюсь?

Курс написан для юристов, бухгалтеров и менеджеров, а не для разработчиков. Каждый технический термин объясняется один раз, простыми словами, и дальше используется только он. Если не хочется трогать git руками — выбирайте путь своей профессии: «Юрист», «Маркетплейсы» или «Маркетолог», там всё в git делает ИИ. Если застряли — в каждом уроке есть, что именно спросить у ИИ.

Сколько времени занимает?

Около четырёх часов чистого чтения и кликов плюс время на собственные эксперименты. Удобный темп — один модуль в день, неделя на весь курс.

Где хранится мой прогресс?

Только в вашем браузере (localStorage). Никуда не отправляется. Если смените браузер или очистите данные сайта — прогресс сбросится.
