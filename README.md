# Курсы: сайт с каталогом, регистрацией и админкой

PHP 8.3 и MySQL, без фреймворка и без composer. Репозиторий целиком кладётся в корень сайта (`www`) и обновляется через `git pull`.

- **Каталог курсов** на главной: поиск, категории, карточки.
- **Доступ к курсу** — один из трёх. *Открытый*: проходят все, без регистрации. *По регистрации*: бесплатно после входа. *Закрытый*: по коду доступа или когда администратор выдал доступ вручную. Любой урок можно сделать бесплатным предпросмотром.
- **Прогресс**. Без входа он хранится в браузере. После входа синхронизируется с аккаунтом. Прогресс, набранный до регистрации, переносится в аккаунт. На общем компьютере после выхода чужой прогресс не остаётся.
- **Админка** по адресу `/admin`: курсы, пути, модули, уроки, пользователи, настройки. В редакторе урока есть кнопки виджетов, живой предпросмотр и сохранение по Ctrl+S.
- **ИИ-помощник** в редакторе пишет черновик урока, квиз, практику с чеклистом или улучшает выделенный фрагмент. Ответ приходит потоком прямо в панель.
- Курс «ИИ для работы: от юриста до программиста» лежит в `content/kurs-ai` и загружается при установке. Он открывается по старому адресу `/kurs-ai/`.

## Установка на хостинг

1. В панели хостинга создайте базу MySQL и пользователя для неё. Запишите имя базы, пользователя и пароль.
2. Склонируйте репозиторий в корень сайта. Папка должна быть пустой.
   ```
   cd ~/aiblocks.ru/public_html
   git clone https://github.com/fleyg2005-png/kurs-ai.git .
   ```
   Название папки корня зависит от хостинга: `www`, `public_html` или `aiblocks.ru/public_html`. Если репозиторий приватный, git попросит логин и токен доступа GitHub вместо пароля.
3. Откройте сайт в браузере. Появится установщик: введите данные базы, название сайта, почту и пароль администратора. Галочка «Загрузить готовые курсы» загрузит курс из `content/`.
4. Установщик создаст таблицы, администратора и файл `config.php` с доступом к базе. После этого он откроет админку, а сам станет недоступен.

Если установщик пишет, что не может создать `config.php`, создайте файл вручную по образцу `config.sample.php` или скопируйте текст, который покажет установщик.

**Обновление** — одна команда в корне сайта. Изменения базы применяются сами при первом открытии сайта после обновления.
```
git pull
```

Письма для восстановления пароля уходят через почту хостинга. Адрес отправителя задаётся в **Админка → Настройки**.

**Что нужно от хостинга**: PHP 8.3 с расширениями `pdo_mysql`, `mbstring`, `curl`, `json`; MySQL 5.7+ или MariaDB 10.3+; Apache с `mod_rewrite` и разрешённым `.htaccess`. Если сайт отвечает ошибкой 500 сразу после установки, уберите из `.htaccess` строку `Options -Indexes`: некоторые хостинги её запрещают.

## Безопасность

- `config.php` не попадает в git: он в `.gitignore`. Никогда не добавляйте его в репозиторий.
- `.htaccess` закрывает `.git`, папки `app`, `content`, `database`, `tools`, файлы `config.php`, `*.md` и `*.sql`. Проверьте после установки, что адреса `/.git/config` и `/config.php` отвечают ошибкой 403 или 404.
- Пароли хранятся как хеши. Вход защищён от перебора: после 10 неудачных попыток почта блокируется на 15 минут. Все формы защищены от подделки запросов.
- Ключ API нейросети хранится в базе и не показывается в админке.

## Персональные данные (152-ФЗ)

Сайт хранит имя и почту учеников, поэтому владелец сайта становится оператором персональных данных.

1. Отредактируйте политику обработки данных: **Админка → Настройки → Политика**. Установщик положил туда шаблон. Укажите оператора: наименование или ФИО, ИНН и адрес. Текст стоит проверить с юристом.
2. Подайте уведомление в Роскомнадзор об обработке персональных данных. Это делается на сайте pd.rkn.gov.ru до начала обработки.
3. Согласие на обработку собирается галочкой при регистрации. Ученик может удалить аккаунт и все свои данные в личном кабинете.
4. Хостинг для базы с персональными данными граждан РФ должен находиться в России.

## ИИ-помощник

**Админка → Настройки → Нейросеть.**

- **Формат API**: «Anthropic (Claude)» или «OpenAI-совместимый».
- **Модель**: по умолчанию `claude-opus-5-5`.
- **Адрес API**: пусто — официальный адрес. С российского хостинга официальные API обычно недоступны. Укажите адрес прокси или агрегатора с тем же форматом API; окончание `/v1` можно писать и не писать.
- **Ключ API**.

Помощник знает разметку виджетов курса и пишет готовый HTML. Скрипты, стили и обработчики событий из ответа вырезаются. Перед вставкой текст стоит прочитать: нейросеть может ошибаться в фактах.

## Как устроен код

```
index.php            точка входа: все адреса идут сюда через .htaccess
app/                 код сайта (закрыт от браузера)
  bootstrap.php      конфиг, сессия, подключение модулей
  router.php         адреса сайта
  pages_public.php   каталог, страницы курса, уроки, API прогресса
  pages_account.php  вход, регистрация, восстановление пароля, кабинет
  admin/admin.php    админка
  ai.php             ИИ-помощник: запрос к API потоком через curl
  courses.php        доступ к курсам, структура для движка, прогресс
  importer.php       загрузка курса из папки content/ и из файла экспорта
  installer.php      установщик
  migrations.php     обновления базы после git pull
database/schema.sql  схема базы
content/kurs-ai/     исходники курса: course.json, home.html, lessons/*.html
assets/              стили, шрифты, движок курса app.js, скрипты админки
tools/dev-router.php роутер для локального запуска
```

Движок курса `assets/app.js` получает структуру курса от сервера и отвечает за навигацию, выбор пути, прогресс и виджеты. Виджеты описываются разметкой: `.quiz`, `ul.checklist`, `.stepper`, `.reveal`, `.tabs`, `.prompt`, `.mock`, `.compare`, `.flow`, `.task-box`, врезки `.note .tip .warn .win .key`. Кнопки редактора вставляют готовые заготовки.

**Перенос курса** между сайтами: **Курс → Экспорт** скачивает один JSON-файл, **Курсы → Импорт** загружает его как черновик.

## Локальный запуск

```
php -S localhost:8790 tools/dev-router.php
```

Откройте `http://localhost:8790/`. Установщик попросит данные локальной базы MySQL или MariaDB.
