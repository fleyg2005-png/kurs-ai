# Курс по ИИ: от юриста до программиста

Интерактивный статический сайт-курс. Без сборки, без зависимостей: папка с HTML, CSS и JS, которую можно положить на любой хостинг. Рассчитан на публикацию по адресу `https://aiblocks.ru/AI-kurs/`.

## Что внутри

```
index.html          главная: описание, карта курса, FAQ
certificate.html    сертификат (появляется после 100% прохождения)
lessons/*.html      уроки и контрольные (по одному файлу на урок)
assets/style.css    стили (светлая и тёмная темы)
assets/app.js       движок: манифест курса, навигация, прогресс, виджеты
assets/favicon.svg
```

- **Общие модули 0–3 и два пути на выбор** (модули 4–7): «Сайт» — свой инструмент как веб-страница на GitHub Pages, читатель сам делает коммиты и pull request в браузере; «Юрист» — документы в приватном репозитории, всю работу с git делает ИИ-агент. В каждом пути 19 уроков и контрольных, общих — 14. Манифест (порядок, заголовки, время) — объекты `COMMON` и `TRACKS` в начале `assets/app.js`. Уроки пути «Юрист» — файлы с префиксом `d` (`lessons/d14-connect.html`), урок регистрации `12-signup.html` общий для обоих путей.
- **Выбор пути** хранится в браузере читателя; блок выбора — на главной и в стартовом уроке (`<div id="track-chooser">`). Открытие урока из другого пути переключает путь автоматически.
- **Прогресс** (пройденные уроки, ответы на квизы, чеклисты, шаги степперов) хранится в `localStorage` браузера читателя. На сервер ничего не отправляется.
- **Контрольные** засчитываются автоматически, когда отмечены все критерии приёмки и квиз пройден не ниже 70%.
- Все ссылки относительные, поэтому сайт работает из любой подпапки (`/AI-kurs/`) и даже при открытии файлов напрямую.

## Как опубликовать на aiblocks.ru/AI-kurs

1. Скачайте репозиторий (кнопка **Code → Download ZIP**) или склонируйте.
2. Загрузите содержимое папки (файлы `index.html`, `certificate.html`, папки `assets/` и `lessons/`) в каталог `AI-kurs` на сервере — по FTP, через панель хостинга или любым другим способом. Файлы `README.md` и `.gitignore` можно не копировать.
3. Откройте `https://aiblocks.ru/AI-kurs/` — должна открыться главная. Серверу ничего настраивать не нужно: это обычные статические файлы.

Если сайт отдаётся через nginx и нужен «красивый» адрес без `index.html`, достаточно стандартной директивы `index index.html;` — она включена по умолчанию.

Для предварительного просмотра можно включить GitHub Pages для этого репозитория (Settings → Pages → Deploy from a branch): сайт откроется по адресу `https://<owner>.github.io/kurs-ai/`.

## Как редактировать

- **Текст урока** — откройте нужный файл в `lessons/` и правьте HTML внутри `<article>`. Шапка (кикер, время), кнопка «пройдено» и навигация добавляются движком автоматически.
- **Новый урок** — скопируйте любой урок как шаблон, поменяйте `data-lesson` в `<body>` и `<title>`, затем добавьте запись в нужный модуль в `COMMON` или `TRACKS.site` / `TRACKS.docs` в `assets/app.js` (id должен совпадать с именем файла без `.html`). Для контрольной добавьте `control: true`.
- **Виджеты** (готовая разметка): `.stepper` с шагами `.step[data-title]`, `.quiz` с `.q` и `li[data-correct]`, `ul.checklist`, `.reveal`, `.tabs`, `.prompt` (кнопка «Копировать» добавляется сама), `.mock` для нарисованных экранов, `.compare`, врезки `.note .tip .warn .win .why`. Примеры есть в любом уроке.
- **Факты, которые устаревают** (модели, цены, кнопки в интерфейсах) — собраны в уроках модуля 2 (`03-claude.html`, `04-chatgpt.html`, `05-choose.html`), в `19-agents.html`, `20-claude-code.html`, `21-codex-copilot.html` (путь «Сайт») и в `d14-connect.html`, `d15-first-task.html`, `d16-codex-copilot.html` (путь «Юрист»). Там указано «на октябрь 2026».

## Локальный просмотр

Достаточно открыть `index.html` в браузере. Для полной проверки (как на сервере) можно запустить любой статический сервер, например `python3 -m http.server 8000`, и открыть `http://localhost:8000/`.
